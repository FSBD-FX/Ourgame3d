# Native room flow proof candidate

This candidate is not compiled or run. Root alone admits Source/tools and starts
UE. It adds two Probe files and a narrow HUD patch. Preserve current Room,
Feedback and world-warning work. The HUD patch only dispatches an opt-in probe
and records actual Guard draw calls; it does not change drawing or gameplay.
Guard uses a procedural early-return draw branch, so its existing sprite-size
map is correctly zero. The new same-frame ID record observes that actual branch
without pretending a sprite existed. All seven exact before/reference files
are retained and pinned; do not overwrite Root's current files with them.

Root may copy the four scripts to tools/scripts and two Probe files to Source,
then merge HUD-probe-dispatch-v001.patch. Compile and freeze a new actual
compiled-source-manifest.json containing Probe.cpp/h, current HUD, DLL, full
registry and Production inputs. The launcher deliberately requires that actual
snapshot argument. No old169/1199 count or invented future snapshot is locked.
The .cmd is intended for the workspace root after admission; Root can seal its
default snapshot only after the actual compiled manifest exists. Until then it
accepts the exact snapshot directory as its first argument.

Run capture-guard-room-native-flow-v001.ps1 -Snapshot <actual snapshot directory>
-Version v001. Its -ValidateOnly checks the real compiled pins without UE. The
native recording starts with the normal /Game/Maps/FirstRoom?
DungeonFirstBatchGuardRoom URL and the current hero72/Sword/Walk/Leather art
flags, with hidden HUD and ordinary pacing. No QA SpawnStoneGuard, teleport,
direct actor HP assignment, manual GameMode Tick or fixed time step is used.

FirstBatch actually starts unarmored. The probe explicitly registers one
display-only LGT source, then drives real Enter/E and the existing .50s armor
commit. This is not room loot. It normally moves to the real initial Knight,
records J accepted native melee hit receipts plus positive actual HP loss, then
records a real Shift dodge. Public ApplyCombatHit advances remaining HP and the
later enemies after a visible native birth; every request is separately logged.
The movie is always a FLOW DIAGNOSTIC, never a normal-J full clear. Failures and
timeouts retain their actual report and originals; no HP/death is forced.

The actual room owns all three identities, seeded anchors, serial2s breathers,
complete1.2s warnings and materializations. Probe captures same-draw rendered
warning IDs, no actor/HP during Warning, native Bat/Guard driver birth clocks,
actual draw calls, real death/report/ground coin objects, normal WASD pickup and
wallet20->40 with exact7/4/9 amounts. It retains six true RootV2 Codec boundary
files: entered, Bat warning, Guard warning, settled Guard Owner2, after pickups,
and installed. Actual grouped Prepare/Install pauses for.6 wall seconds at the
saved sim/wallet, byte-compares the entire Codec, then resumes only with fresh
real Enter and checks no death/coin duplication. This is one-process grouped
continuation, not DiskV2, true2PID, room-exit or full D13 acceptance.

verify-guard-room-native-flow-v001.py independently checks every original1280x720
PNG against native BGRA CRC, exact FIFO receipts, stop/flush, ordinary event
timing, actual J/Shift, rendered warnings/births, finite rewards and exact saved
Codec equality. Technical pass remains separate from Root visual review. The
silent movie does not certify audible Feedback audio. Enemy art remains its
actual current placeholder; old unsupported player states can use existing
fallback presentation and are recorded, never silently redrawn by this probe.
Actual rendered texture paths, stack, special-presenter support and sprite/canvas
size are recorded in every native frame. Hurt/Dodge/Death are unfinished art;
the real Shift sample deliberately retains any old human identity/size defect
as evidence for repair. No all-state72 or main-character art pass is claimed.

After an actual passing capture, run prepare-guard-room-native-media-v001.py
--archive <actual archive> --retain-name 2026-10-18-石廊三敌原生流程诊断-v001.
It makes a silent VFR video from original capture-event times, fully decodes it,
copies eight actual native sample frames without resizing, and preserves all
originals/presentation copies plus source/version/status index in a fresh E
folder, verifying every copied byte/hash. Root must complete/review E retention
before any media View or presentation. The helper does not view images or open
a player, and it never overwrites an earlier archive.

Normal trial: launch-guard-room-native-trial-v001.ps1 -Snapshot <actual snapshot>
[-LightArtTrial]. Pure mode uses the normal room URL. LightArtTrial only registers
one public display light-armor source; Enter/E/J/Shift/WASD remain user input,
with no probe-driven action or damage. The .cmd selects this explicit art-trial
mode. Normal room/kernel/reward rules remain authoritative.
