## 静态判断

142 的可见近侧髋下，较宽大腿直接向下延续成站立腿，膝部轻弯后接向身体下方的平底支撑靴。这条大腿是前景实心形状，不再像原 140 一样从前髋横跨到右前方摆腿。裤裆右侧的远腿近端处于这条前景大腿之后，再从其右边缘显露，斜向低前膝，向下接到前方离地靴。遮挡与连接在本张里能支持 far passing 的解释，而非仅换 near/far 标签。

141 的前景大腿则从可见近侧髋向右前膝斜出，接前方抬靴；另一腿的上段处于其后并向左下支撑靴延续。将它与 142 并看，前景大腿由「前摆斜股」改为「向下支撑股」，符合目标的相反静态角色。灰裤本身没有物理左右标记，所以结论依据固定三分之四摄像深度和实际轮廓遮挡；没有用右侧靴就必定是 near 的错误规则。

两张均可见恰好两腿和两个完整靴；142 未见多出大腿、髋根断开、融合膝或腿伸进身体的明显错误。抬膝低于腰带，抬靴处于前方并有清楚离地间隔，不是后踢或高抬膝。142 的摆靴比原 140 稍高、靴与踝角也变化了；目前仍可读为低前抬的单姿势。这里没有测量或锁定真实足根、接地跨度、间隙或腿长数值。
