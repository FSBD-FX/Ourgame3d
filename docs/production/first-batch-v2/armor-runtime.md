数据取自已有 `DungeonContentCombat::GetArmorDefinition`，是先前设计初值，尚未做试玩平衡。换装需要地面闲置0.5秒，提交前继续使用旧甲；期间阻止普通攻击、移动、跳跃和换武器，实际受伤取消未提交换装。成功换甲不治疗、不补专注、不刷新上次消耗时间。法袍恢复替换基础12/s，实际消耗后均等待1秒；不足专注时拒绝且不扣数值。

物理和魔法直接伤害分别读取护甲/魔抗，减伤率为 `min(0.60, rating / (100 + rating))`。当前玩家普通三段近战只发物理伤害；魔法入口已用实际HP变化验证，法杖的发射与资源链仍未接入。附魔、强化、天赋与遗物最终属性合并尚未接入，不能把表内基础值当作完整属性系统已完成。

测试 `CodexDungeon.Content.ArmorSwapAndStats` 先在可编译空实现上真实失败，再在真实UE world中通过。验证包括换装半途旧甲、攻击互斥、实际移动距离、护甲14把物理11.4减到10、正伤取消、三套后续模板的速度/韧性/魔抗、专注消耗和延迟恢复、法袍50魔抗把魔法15减到10、不足资源拒绝以及换甲不回血。
