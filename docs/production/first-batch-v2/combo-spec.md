## 接段与中断

- 接受主攻即固定本段完整时轴，40%前摇锁定朝向及其余攻击属性。每段前摇、有效期、完整后摇结束后，才可开始下一段。
- 每次按下攻击只登记一个意图。最后0.12s可缓冲下一段一次；更早点击不排队，多次点击不累积。第三段末缓冲可在完整收势后开始下一轮第一段，不给予无限输入队列。
- 结束后0.45s内再次按下延续下一段，超过该窗口从第一段开始。精确到期时先过期再接受输入。按住不自动产生新的按下事件。
- 空挥也推进段数；命中不是继续条件。每段独立AttackID，连续有效期同一目标最多承受一次本段伤害；重复渲染、音效及命中闪光不能再结算。
- 一次离地仍只允许一次主攻。空中主攻只执行第一段并结束地面链；落地不取消、不重开该段，也不解锁第二次空中攻击。不得用跳跃跳过原后摇。
- 锁定前反向取消、真实破韧中断、死亡、接受换武器、开始技能/闪避/交互等其他独占动作，均清缓冲及地面链。普通未破韧受击只有反馈，不凭播放hurt取消本段；中断动作与后续重新起攻使用新AttackID。
- 下一段按正常起攻规则再次锁向；已锁的本段不追踪目标。只有合法闲置或锁前方向修改能改变朝向。
- 局部命中停帧仅影响展示姿态，保持地面位置/阴影/跳跃/投射物/DoT/CD与权威动作时钟推进；下一权威关键事件抢断展示停帧。

## 表现与保存合同

三段须有不同预备、击出、接触、收势关键姿态以及回待机/接下一段的衔接，武器握点和防具同骨架逐帧匹配。特效方向、范围与真实判定一致；空挥、实体命中、石材/肉体、防御/破韧声音分别驱动。连击计数显示只消费真实命中事件，不造成额外奖励或伤害。

保存活动动作的AttackID、段数、累计权威时间、固定时轴、锁向/属性快照、每子击已命中目标、剩余续段窗口及离地攻击标志。沿D02/D11/D13，暂停/保存/恢复须清尚未执行的攻击输入缓冲；继续不自动挥击，玩家须重新按键。该清理不取消已有动作、不清连段进度，暂停期间权威时钟不前进；继续不重新起攻、补发既有命中、重抽暴击或重新播响已经消费的声音。核的Capture/Restore可保留内部缓冲用于确定性单元测试，磁盘存档适配必须先ClearPendingInput。

验收至少包括：连续/稀疏输入、过早输入、缓冲边界、低帧率跨多窗口、左右锁向、槍最短距离、空挥、同目标去重、破韧/普通受击区别、第三段回第一段、空中一次限制、换武器断链、动作中保存继续、静音与低特效。当前状态：规则已明确，未制作完成，未运行验收。
