# 首单元动作候选的运行组装

初批角色30帧与石像苏醒6帧按冻结 `import-subset-v001.json` 导入，引擎逐项核对Texture2D、512尺寸与源SHA。另导入独立军剑；初次36帧收据保留为 `content-sprites-v001-import-initial-36.json`，37项当前收据为 `content-sprites-v001-import.json`。导入不代表换装层、动作或手握已验收。

`assembly-markers-v001.json` 保存逐手审图的30个握点、作者指定的剑角度与近手多边形候选。`prepare-content-assembly.py` 只读图片核SHA、尺寸与实际手像素alpha，生成版本化C++标记，未改PNG。运行按真实动作阶段分配预备2帧、有效2帧、收势2帧，独立武器以实际grip为旋转中心；近手层只重绘多边形内的原身体像素，不绘制虚构手掌。衣服仍烘焙在身体内，不能冒充可替换防具层。

左朝向只镜像一次：身体U宽为负，握点位置围绕共同root反射；剑纹理同样只镜像一次，再使用负的右向旋转角，让最终剑向为180°−右向角。近手层保持原图UV并反射屏幕多边形，避免手纹理反向两次。

原标记的0.55剑缩放在idle推算使刀尖低于足根50源像素；`DungeonCandidateAssemblyTuningV001.h` 另存0.40候选缩放及少量角度调节，保留原作者标记。该算术只能排除明显的休息姿势穿地，实际左右朝向、动效衔接及攻击可信度仍须运行审阅。站立手是张手、行走手大多放松，不能因握点alpha有效就宣称握持自然。

当前仅 `-DungeonCandidateSprites` 打开候选显示；正常原型仍独立保留。全部22逻辑动作/122独特帧的后续冻结子集、跳跃虚拟根、石像阶段和死亡pose-aware审阅在继续准备。本文件不是完整军剑/轻甲/石像骑士验收单。
