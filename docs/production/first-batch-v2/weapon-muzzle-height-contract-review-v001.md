# 武器图像发射口与战斗高度：坐标契约审查 v001

2026-10-15，root汇总ranged_review源码检查；仅契约分析，未改发射权威，未批准完整武器。

## 事实

当前战斗Height是地面/离地高度基准：地面角色0、跳跃实时高度、石蝠高90/低20。近战/弹体高度差65及蝠地面body40是既有规则，实际UE62已覆盖相关边界。XBW ready-idle合同的二维Emit相对root为(139.4074093463,-184.9693773008)源像素；512画布显示160时是(+43.5648154207,-57.8029304065)逻辑屏幕像素。

HUD屏幕Y同时含groundY投影、JumpHeight投影和身体局部像素；单个二维点不足以唯一求出物理groundY与Z。若把ready发射口竖直差全解释为高度，则约加82.5756cm，地面角色原H0的弹会与地面H0目标差大于65。该做法改变玩法，不能当作普通渲染修正。射击frame2的Emit与ready不同，更不能统一套待机点。

当前XBWReady显示的Emit是实际持弩矩阵算出的只读屏幕观察。它没有写Actor、WA或世界弹体；现世界发射口仍沿旧逻辑，不能把这次idle画面称为真实发射口接线完成。

## 推理与建议

先明确两种坐标，再继续实现。CombatHeight继续表示离地战斗层，保留现正式65规则；图像发射口属于身体姿势局部坐标，其显示位置由同一姿势/武器矩阵投影。若需要弹体从可见弩口离开，可由Actor在真实发射端点冻结只读的展示socket数据，HUD只消费这个事件，不能在DrawHUD时回写发射位置。

该最小路径必须明确展示socket与当前combat-plane origin是两个量；画面改善不等于物理Muzzle同坐标。若要把socket确立为世界权威发射点，则必须额外确定一个可逆的rig坐标约定：局部像素分别对应groundX/groundY/高度或固定美术偏移，目标hurt锚点也须同基准；不能只挑一个能让现测试通过的Z偏移。起攻锁定方向、发射时实际位置、事件时刻及range起点需由Actor/WA共同消费，并版本化记录。

推荐先完成同姿势Grip/Support/Emit三点、实际射击和装填身体及各甲遮挡；随后在Actor端实现姿势采样与发射事件冻结。所有显示与碰撞调用同一份已明确含义的数据，逐个证明真实端点及单次镜像。姿势没有完成前不移动战斗权威。

## 风险与必须补验

- 枪口前移可能越过贴身墙/敌，必须验证从角色到发射口的真实阻挡，不能靠将弹体出生在墙后穿透。
- 地面/跳跃/落地中发射，左右朝向、多发与技能，须各按发射端点取姿势；HUD帧率不能改变命中、Ammo、Focus或CD。
- 同点死亡/破韧/装备提交仍先于合法发射；只读展示事件不能创建第二次攻击或音效请求。
- 正式65高度、蝠body40、16×12 hurt和旧武器范围不能因图像换装暗改。若实际rig需要新的hurt基准，应明确修订合同与独立反例，保留旧验证来源。

上述是后续契约建议，尚未实现或实跑；XBWReady9只验双手待机与现有单发/装填玩法，不认证完整世界发射口、四甲、射击/装填美术或音效听感。
