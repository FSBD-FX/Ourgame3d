### 全 bbox 居中的额外风险

原稿盔 core横向中心仅约4px跨度，全轮廓中心却有30px跨度，主要来自摆臂/脚展幅。若 shared scale 后仍逐帧按**全身 bbox-center**放置，就可能在原稿本来稳定的头/躯干上额外施加水平位移。以仅供量级估算的416/1043共享比例，30原图px约为12px/512画布；88.615画布显示约2.1px。此数值不是已提取/已运行观测。

因此新row应记录每帧原cell、组件bbox、shared ratio和placement offset，随后用这些变换解释身体/脚的位置。最终x256只代表放置策略；单脚支撑时两足平均也不自动等于身体运动root。不要为“平稳”偷偷逐帧重缩放、改姿势或把脚根移到全bbox中心。原稿没有被本审查移动，最终pivot仍待真实测量/运动审查。

## 进入实验的判断及观察顺序

六张相反contact/passing/precontact的角色来源现在齐备，关键髋遮挡已比失败整行清楚，足够作为**固定原序、固定原83ms时序的实验输入**。不再需要靠重命名1/4或把contact当precontact凑数。此次同次shared提取能够揭示不同单图fit曾掩盖的尺度/位置问题，值得先看完整效果再决定下一步。

最可能可见的跳变依次是：

1. **0→1与3→4的落足/体重转移。** 前伸靴收回骨盆下的距离较大，尤其0→1；passing的头部在原图更低一些，而不是合同描述的轻微上升。统一底边后1相顶点比0约低23px，约1.6px的小角色显示量级；需分辨是合理腿压缩、原图比例漂移还是落脚瞬移。
2. **1→2与3→4的近手轨迹。** 大手由躯干侧面中位到横胸前摆的跨度明显，六帧12Hz可能读成突然切换。2→3/5→0又处于峰值邻接，存在节奏一快一停的风险。这里只是静态序列推断，没有实际播放结论。
3. **两半周期摆靴高度和脚根。** 检查前景/后景腿始终从原髋连续经过、支撑脚是否滑动、抬足是否落成后踢或混肢；不要用全bbox重心/两足平均替代其证据。
4. **5→0接缝与盔体。** 145前near跟需要落到138接触轮廓，手套/袖口/前靴鞋头略有形状差异；检查连续接缝是否出现体块、视窗/眼形、铆钉或轮廓重置。原图绿背景没有地面线，不能凭背景证明鞋根一致。
5. **实际小比例与左右显示。** 在原生可辨的遮挡、前跟间隙和手指可能在72px身高丢失；左向应在实际显示中确认镜像/pivot正确，不能从朝右六张推定全部适配。

依据 sprite-gen 的 `docs/qa-motion.md`，walk 属实验性 locomotion，motion continuity 与loop seam必须从真正播放判断。后续应先保全新row/contact/preview，再实际看0→1→2→3→4→5→0，多圈比较、再小尺度/双朝向验证。本审查没有看循环，没有最终root/stride、无动态通过、无正式导入或用户终批；完整内容目标仍0/15。
