## 目视判断

- **胸、肩、护臂、护胫确实有各自大形。** 胸片是短而完整的一块，两个圆角肩盖形成小台阶；左右护臂与棕手套有黑边分隔，胫片结束在靴口上方。胸片/护臂/胫片的大亮面与暗侧面，比原型仅靠炭灰衣服内部折线更容易辨认。圆铆钉是辅助，去掉小铆钉也仍有甲形。
- **关节和身体仍读得出来。** 盔下暗领、胸下腰带、两肘炭灰袖、裤腿与膝弯露出；甲没有连成从头到脚的整壳。两手空着，棕手套、手指和靴头可辨。腿间保持负空间，没有裙板/披风把下半身连成一块；本图是站立，不能推定收腿步态也有同样间隙。
- **身份连续，但属于重绘参考。** 钟形封闭盔、歪顶栓、盔侧圆钉、黑眼窗与两枚琥珀眼均保留，右向三分之四姿态、短腿、大头和棕手靴延续131。原图边线、磨损块、眼形/开窗细节和衣褶经过重绘；没有依据称头盔、手脚或身体像素未变，更不能把146主体作为131不变公共身体的生产替代。
- **轻重边界暂时可守住。** 肩盖短且圆，胸片紧凑，手肘/上臂/裤腿大量露底衣，没有门栓胸横梁、方宽肩、整腿厚板或挂裙，未读成既有HVY门栓板甲。但胸片仍是完整金属块，不能仅凭此图正式绑定行路短衣；后续四甲并排时须保留轻/中/重三者的轮廓差。
- **怪诞程度来自角色形体，盔甲本身较朴素。** 夸大的钟盔、发光眼窗和小身体保留了古怪感，甲以圆角旧板和不规则涂色承接，未变成尖刺恶魔甲或写实骑士。没有看到额外肢体、裸肤、武器、盾、文字或场景。要继续增强怪诞时，宜先从器具形状/结构变化判断，不宜马上增加小挂件堆积。
- **颜色有一项待验证风险。** 甲面偏暖的沙灰/铁灰，与头盔接近；黑领和肩边目前把头与胸分开。缩小时黑领若只剩很细一条，暖盔和胸肩仍可能合成大亮块。护臂与棕手套、胫片与棕靴目前有边线和色差，但这张大原图不能证明72像素下仍分得开。

## 实际透明数据及边缘限制

146的alpha extrema为[0,255]，透明alpha0共1,242,348像素；alpha1–15共9,901，16–127共3,688，128–253共313,065，254共2,312，255共1,202。其中alpha253有273,463像素，占主体大部分。少量纯255不意味着整个角色明显半透明；也不能只检查RGBA模式便称透明提取已完成。

非零alpha bbox为[0,23,1226,1254]，45个画布边界像素非零，最大alpha仅1；alpha≥16 bbox为[370,116,899,1162]，alpha≥128 bbox为[371,116,898,1161]，没有alpha≥128边界点。bbox采用半开区间。也就是说，主体留有余量，但极低alpha散点让非零外框触边；直接按非零bbox缩放/贴地会误判主体范围和根。这里没有据阈值修改图片，alpha≥128外框也不是足底接触中心。

对照131的非零/alpha≥128 bbox均为[146,48,367,464]，非零边界为0。146原生参考并不直接符合131最终512画布/根约定。此次工具显示的透明区和大图边缘没有明显实色背景或白色厚轮廓，但未在多种底色/真实引擎采样上逐边检查，仍不能证明不存在alpha杂边、缩小后暗边或颜色泄漏。
