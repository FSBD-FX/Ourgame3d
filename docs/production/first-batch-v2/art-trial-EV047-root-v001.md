## 推理

独立造型便于继续建立方向锚点及可替换装备，不应把整张场景概念当作可直接行走的地图。生成模型对精确尺寸的服从不足，继续反复改整图无法替代UE中确定的显示尺寸/根点/身体碰撞分离。下一步应从独立图片进入可控的组件制作与小范围实景试装，再展开动作。
