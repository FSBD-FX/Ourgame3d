# 武器与防具设计 v1：共同规则

日期：2026-10-12（Asia/Shanghai）。状态：**设计稿；未接入游戏、未经试玩调平衡、未获逐条验收**。本目录是原创内容设计，不是《失落城堡》的条目或数值复刻。

## 已确认要求与本轮设计边界

用户要求刀、枪、剑、戟、弩、各种热武器、法杖具有明确不同的攻击方式，每种先设计三把；明确举出小刀、大刀、重剑的重量感和长枪的速度、戳刺、距离差异。防具包含轻甲、中甲、重甲、法袍。本轮先做武器与防具，道具和敌人整理保留为后续工作。

为使动作区别可制作，助手将这些类别细分为 **11 个动作家族 × 3 把 = 33 把**：KNF 小刀、DAO 大刀、SWD 单手剑、GSW 重剑、SPR 长枪、HAL 戟、XBW 弩、PST 手枪、SGN 霰弹枪、RFL 步枪、STF 法杖。热武器的三类划分、每类具体条目，以及 **四类防具各三套，共 12 套**均为本轮设计建议；并非用户指定的最终发行上限。现有斧原型保留，未被这次目录删除，后续可另立家族。

## 共同战斗基线

- 地面 XY，朝向沿 X 正负；跳跃高度 Z 独立。所有范围使用逻辑世界 **cm**，时间 **s**。`range_cm` 是朝向前方距离，`depth_halfwidth_cm` 是地面 Y 的半宽，完整纵深宽为其两倍；不把画面像素当作射程。高度差暂定不超过 65 cm；投射物记录发射高度，不能无条件打中高空目标。
- 范围的硬边界统一按**目标地面逻辑中心**裁定：`x=(TargetX-OriginX)×AttackerFacing`，`y=TargetY-OriginY`，先检查条目的最小/最大 X 和 Y 外包络，再做具体形状精检。近战横扫/斜斩使用前半椭圆 `(x/R)^2+(y/D)^2≤1`，并按 min_range 裁剪；直刺/锥刺和重剑窄劈/砸击使用 `[min_range,R]×[-D,D]` 矩形。戟刺/扫分段各用各的形状；霜扇使用条目写明的三角。外包络角点不等于扫击可命中点。
- 投射物/霰弹几何精检采用基础逻辑受击矩形：玩家和标准人形/兽人目标相对中心 X 半长18、Y半宽16 cm，跳跃高度仍单独检查65 cm；Boss或异形尺寸需未来按敌人定义另配。飞行弹连续扫掠，霰弹为射线加条目弹丸半径对该受击体检测；**受击体不能绕过上一条中心硬边界**。因此不同目标体型影响同枪命中丸数，却不让中心在射程/最大纵深外的目标额外中弹。近战不额外膨胀受击矩形，保持旧原型中心判定的可解释性。该模型是可制作的首轮近似，正式美术缩放不得暗改它。
- 参考玩家 100 HP、移动 265 cm/s；旧剑 26 伤害、135 cm 范围、52 cm 纵深半宽只是原型参照。所有新数值均为待实测的初始配置，不能据此声称平衡。无随机暴击、无全局耐力条；重量通过前后摇、移动限制与打断风险体现。
- 主攻击 J / 鼠标左键；K / 鼠标右键为武器技，T 装填，Q 切换两个携带武器槽，E 拾取 / 替换，I 查看装备（以上新增操作为建议，未实现）。R 仍用于死亡后重开，避免与装填冲突。近战和武器技限地面使用；空中主攻击后续专项设计，不用已有跳跃攻击推定 33 把都可空中施放。
- 一次主攻击触发的名义单目标伤害记为 `damage_total`，多段完整命中时求和；散弹按同一枪的弹丸合计，不能拿每丸伤害直接充当整枪。范围攻击可对多个目标分别结算，但同一挥砍对同一目标只命中一次。多段使用独立子命中 ID；同一霰弹枪齐射先合计再做一次受击判定，避免旧原型无敌帧吞掉后续弹丸。
- `cycle_s = windup_s + active_s + recovery_s`，均是动画/操作时间；前摇结束才开始命中。主动窗口不是持续伤害。主攻击在有效窗及后摇不可跳跃取消；前摇的前 40% 可用反向移动取消且不造成伤害，达到 40% 时锁定朝向；普通同向移动不取消攻击。移动倍率在整个攻击期间生效，受伤等其他状态与武器倍率取更低值后再乘防具倍率。输入最多缓冲下一次攻击 0.12 s，缓冲不绕过资源、装填或冷却。
- 武器技独立完整动作与冷却，在待机或主攻击后摇结束后使用，不能插入取消主攻击；本轮没有武器技额外无敌。武器技普通移动默认继承该武器的 move_multiplier，条目明确写出更低倍率/站定时以更严格值为准；条目明确的固定步进/后撤另按所写 cm 执行，遇障碍即停，不提供穿人或穿墙。切换动作 0.35 s，仅待机或动作完整结束可触发，保留各武器弹匣、资源与冷却；装填可取消但进度清零且未完成不回弹，防止切枪绕过后摇/装填。
- 近战/子弹为物理，法杖按注明元素造成魔法伤害。无友伤为单人设计默认，后续合作另验，不能据此宣称联网兼容已完成。近战不消耗弹药；弩与热武器首版为**无限备弹、有限弹匣、必须装填**，将装填节奏先做清楚，消耗型弹药掉落另行设计。射弹沿地面朝向直线运动，发射后不能自动转弯或自动跨纵深瞄准；阻挡物/首个目标截停，穿透须逐条明示。
- 法杖共享角色专注值 100，停止消耗 1 s 后每秒恢复 12；切换武器不重置或立即回满。主攻不足不能发射，也不降级免费攻击；HUD 显示不足。无道具或防具时也能自动恢复，避免无资源软锁。主攻与武器技都在前摇 40% 锁定点预留本轮全部弹药/专注，每次实际发射逐发扣除；受击中断只返还未发射部分，已经发出的不退还。恢复倒计时从最后一次实际消耗开始，预留/退还不重置倒计时。武器技冷却自锁定点开始，打断/返还不刷新。开始前资源须足够完整一轮，短点射不因缺弹偷偷减少弹数。
- 主攻受击可被打断；`stagger_total` 为削韧点，不等同生命伤害或硬直秒数。普通敌人示例韧性阈值 40，受击 1 s 后按 20/s 消退，达到阈值触发 0.40 s 硬直并清零，随后 1.0 s 不累计削韧但仍受生命伤害；Boss 示例阈值 160、硬直 0.25 s、保护 3 s。具体敌人阈值后续设计；此机制替代持续受击无限打断，不能与旧每击强制 0.2 s 硬直叠加。
- 角色基础韧性阈值 30，敌方削韧另配；玩家同样在停止接受削韧1 s后按20/s消退，破韧硬直0.40 s、随后1.0 s不累计削韧。被击中仍有生命损失和反馈，未破韧不强行中断动作。玩家基础受伤无敌暂沿用 0.65 s；被该无敌拒绝的攻击不造成生命伤害、不累计削韧、不触发装备特性；同一已接纳攻击的独立子命中/同枪聚合仍遵循攻击ID规则。与攻击 ID/散弹合并规则一起改造，不能默认所有来源共用旧判断就足够。
- 仅本地表现用短命中停顿建议轻 0.025、标准 0.045、重 0.075 s，上限 0.08 s；用表现层停帧/音效表达，不能暂停全局逻辑、冷却或未来服务器。角色阴影保持接地，挥砍轨迹不扩大真实判定。

## 防具规则

首轮每套是**一个身体防具槽的整套装备**，不是头胸手腿分别各 12 件。四类依靠剪影、移动、韧性和物理/魔法保护形成区别；不得把法袍做成只少一点防御的轻甲。武器与防具独立装配，不锁职业。

物理减伤 `min(0.60, armor / (100 + armor))`；魔法减伤 `min(0.60, ward / (100 + ward))`；伤害用浮点计算，内部不逐丸向上取整，HUD 最后显示整数。无负数护甲/抗性。本轮不设置同类相加的额外百分比减伤，避免重复乘算。固定值 armor / ward 只由当前一套身体装备提供；替换先撤掉旧属性再加入新属性。

防具移动倍率作用于 265 cm/s 基础值，再乘武器攻击移动倍率；例如重甲 0.85 与重剑 0.2 同时成立，攻击时为 45.05 cm/s，不能只取较大倍率。防具韧性加成作用于基础阈值 30。跳跃高度与拾取范围不随盔甲降低，避免既有房间失去可达性。专注上限固定 100，法袍可调整恢复率/延迟；本轮不引入最大生命变更、闪避率、耐久与强化等级。

防具效果仅当前套生效，不叠穿；触发冷却挂在角色上，卸装/切换不刷新，同类触发不由自己造成的额外伤害再次触发。替换用 0.5 s 站立动作，可被受击取消；完成前旧甲仍生效，无换装瞬间回血/回专注。拾取前显示两件差异与负面代价，不仅显示绿色总战力。

## 状态共用约束

燃烧：每秒 2 魔法伤害、3 s，总额 6，同目标仅一份，重施刷新不叠加；燃烧不削韧、不触发新武器/防具特效。寒缓：移动减速 20%、2 s，仅刷新，Boss 减速 10%；不减攻击动画速度、不冻结，不与同类减速叠加。电震：一次 8 额外削韧，同目标内部冷却 2 s，Boss 4 s；不连锁递归。只有明确写出的武器技/特性施加这些状态，不能给所有元素普攻隐含附加全套效果。

穿透最多两目标，第二目标伤害 60%，不会无限穿透；推/拉最多 40 cm，不拖拽 Boss，不越房间边界、不改变跳跃高度。武器技眩晕同样服从破韧保护，不额外无条件眩晕。玩家免伤只由基础受伤无敌提供；本轮武器/防具不添加常驻无敌或减伤超过 60% 的特性。

所有推拉随施放朝向镜像：推离的 X 位移为 `AttackerFacing×距离`，拉近为 `-AttackerFacing×距离`，Facing只取±1；向左攻击不能仍固定朝世界X正向推动。后撤为自身 Facing 的反向，步进为同向，均受边界/阻挡约束。

霰弹首轮采用**发射时固定扇形瞬时射线判定，短弹迹仅表现**：同一枪全部弹丸在同一逻辑步检测，按目标合计伤害/削韧/推力，然后各结算一次；不等待弹丸飞完射程才扣血，不创建会再次造成伤害的飞行弹体。双响分为两枪，在各自时点分别检测/合计。条目的 Y 半宽为最大射程处实际包络半宽，最外射线中心加 5/6 cm 弹丸半径等于该值；扇形内部并非必中，仍须射线相交。单孔铅柱武器技单独使用实体弹，不套用齐射处理。这项取舍优先避免延迟受击，同时简化旧无敌帧迁移，尚需试玩验证视觉与命中一致。

普通弩矢/枪弹的 Y 半宽是单发弹体判定容差，不随距离自动扩大；投射物中心起点为发射者地面 Y。霰弹瞬时射线与电杖瞬时电线的 projectile_speed 为 0，表示不创建逻辑飞行弹体；其他飞行弹必须大于 0。攻击形状不能仅用同一个矩形字段还原，须读取逐件 pattern/action。

若条目写“按目标 75% armor 结算”，仅该次物理命中先将目标 armor 乘 0.75 再代入同一公式；不减少目标持久属性、不作用 ward、不与其他穿甲重复叠加，魔法不受影响，减伤上限仍为 60%。未明确注明的攻击不继承穿甲。

## 数据约定

武器 ID：`WPN-家族-001..003`，防具 `ARM-LGT/MED/HVY/ROB-001..003`，稳定 ID 不随中文改名变更。每份 JSON 顶层为数组，UTF-8；每项 `status` 固定 `design_only`。同家族三把是有代价的不同选择，不用纯粹白/蓝/紫加数值充当三个设计。

武器共同字段：`id,name,family,role,damage_total,damage_expression,windup_s,active_s,recovery_s,cycle_s,range_cm,depth_halfwidth_cm,min_range_cm,move_multiplier,stagger_total,magazine,reload_s,ammo_per_trigger,focus_cost,projectile_speed_cm_s,primary_pattern,secondary,trait,tradeoff,animation,audio_vfx,acquisition,status`。近战 magazine/reload/ammo/focus/projectile_speed 都为 0；弩/枪 focus 为 0；法杖 magazine/reload/ammo 为 0。`secondary` 含 `name,action,damage_total,windup_s,active_s,recovery_s,cycle_s,cooldown_s,range_cm,depth_halfwidth_cm,stagger_total,ammo_cost,focus_cost,tradeoff`，特殊条件写在 action，不省略冷却/代价。主动窗口内具体多段/射弹数量、延迟与命中限制写入 pattern/action。伤害默认单体完全命中名义值，不包括另注状态持续伤害或次级目标。

防具共同字段：`id,name,type,role,armor,ward,move_multiplier,poise_bonus,focus_regen_per_s,focus_regen_delay_s,trait,tradeoff,appearance,acquisition,status`；非专注型基础恢复仍填 12 / 1。条件触发效果在 trait 明确数值/限制/冷却，不能用“少量”“大幅”“概率”代替规则。不要创建未经定义的新状态；没有套装效果，12 项是单件整套防具。

获取阶段只用“基础池 / 第一章奖励池 / 第一章精英池 / 后续章候选”等设计标签，不编造已经存在的敌人/商店/掉落概率。实际掉落系统与经济另行设计。本轮装备不跨死亡保留；暂不改造现有原型死亡重开流程。各文档应写清动作识别、优势、代价、反例与待制作资产，数值与本 JSON 一致。

## 当前原型与实施缺口

目前只有剑/斧原型和共享挥砍帧；没有本文的新武器库、防具槽、专注、子弹、装填、武器技、韧性或装备面板。目录中的单手剑不因旧剑存在而自动标为已实现；原型剑仅作伤害/范围参照。二维持握点、不同家族动作、攻击 ID、投射物碰撞与伤害聚合、属性重算和 UI 均需另行制作和实际试玩验证。
