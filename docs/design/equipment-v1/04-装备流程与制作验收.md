# 装备流程、制作依赖与验收 v1

日期：2026-10-12。状态：设计，尚未实现。条目与规则入口见[总览](../../../武器与防具设计总览.md)、[共同规则](00-共同规则.md)。这里的验证均是下一阶段待执行的验收场景，不能登记为本轮试玩通过。

## 获取、携带、替换与死亡

1. 建议新一局使用单手剑家族基础款 `WPN-SWD-001`；第二武器槽空，身体槽空。此为新系统开局建议，未修改当前原型的开局数据。无甲基础护甲/魔抗均为 0，专注 100，基础韧性 30。物品无耐久、不需修理。
2. 武器/防具放在地面，具有稳定内容 ID 和独立实例 ID。E 选择前方/附近最近的有效物品：距离暂定 X 80 cm、Y 半宽 40 cm，角色须落地。多个物品按地面距离、实例 ID 稳定排序；提示清楚指出目标，E 先拾取，再处理出口。
3. E拾取/替换武器只能从待机开始，需完成0.35 s装备动作才提交归属与切换；攻击、受击、跳跃、装填期间拒绝开始，不缓冲成免费换枪。空武器槽优先接纳新武器并切为当前武器；双槽满时替换当前槽，旧武器掉在脚边并保留弹匣/实例状态。动作被受击/移动取消时，地面与槽内物品都不变。已装备同名武器不合并成攻击力，也不能借反复拾取回满弹匣。切换保留每件武器自己的弹匣、武器技冷却；丢弃再拾取仍保留冷却截止时间。
4. 身体槽空时 E 装上；已有防具时显示旧→新保护、移动、韧性、专注恢复及特性变化，再进行 0.5 s 换装。完成才把旧甲掉到地面；受击/移动取消时新旧归属都不变。身体槽至多一套，不叠加旧甲属性。开局无甲仍可正常过门、跳跃和攻击。
5. I 打开对比面板，单人可暂停查看；面板不作为战斗中瞬间换装入口。关闭面板继续。显示物理/魔法减伤百分比、基础与当前移速、削韧、武器距离、主攻周期、弹匣/专注成本，以及负面代价。未来合作不使用全局暂停，另行实现。
6. 第一版装备都在局内获得，死亡重开清空实例与临时冷却；未来图鉴解锁、局外成长、永久掉落解锁和存档另设计。武器不设职业限制；近战+法袍、枪械+重甲均合法，效果由规则决定。
7. 获取池只作设计标签，暂不承诺权重、价格或“击杀某个尚未制作的敌人必掉”。第一章奖励池和精英池作为后续地牢/敌人制作接口；当前只用调试柜完整取用 33+12，验证后接入正式来源。

## 攻击与资源的可观察状态

武器状态顺序：待机 → 可取消前摇 → 锁定前摇 → 有效窗口 → 后摇 → 待机。受击打断需先经过韧性判定。前摇、后摇、冷却、投射物飞行寿命分别存储，不用一个原型 AttackTime 变量承担全部状态。

弹匣武器为待机/攻击/装填；最后一发完整后摇结束时可自动开始装填，弹匣未空可按 T 装填。装填期间以防具基础移动速度的50%移动（不乘射击攻击倍率），移动本身不中断；T再次按下取消，Q先取消装填再进入0.35 s切换。取消当帧不发射或刺刀攻击，下一次J/K输入才可从待机起招；空弹时T取消后不立即再次自动装填，须T手动重新开始或下次完整耗尽弹匣才再自动开始。取消不加弹且下次从零开始，受击打断同样清零。弹匣补满仅在装填完成发生。每次主攻发射数在锁定时验证，弹匣不足完整短点射或武器技时拒绝开始并显示原因；不偷偷变更齐射伤害。新生成实例初始满弹；备弹无限为首轮节奏方案，UI 显示“∞”备弹，不伪装成弹药消耗系统已经完成。

法杖专注消耗和不足有声音/数值反馈；停止消耗 1 s 后自动恢复，每套法袍的替代恢复参数作用于角色。UI 不足提示不能只有换色。切到物理武器仍按原倒计时恢复，不重置专注。所有施放成本、武器技冷却与武器实例绑定/角色共享的字段见[共同规则](00-共同规则.md)，避免切换免费施法。

主攻默认单次按下触发一轮；可以连按并使用 0.12 s 缓冲。没有暗设所有武器按住自动连发；步枪短点射属于一次触发内多弹，必须逐颗记录子命中。需要蓄力的武器技以该条目的完整动作说明为准，不能借松开按键取消锁定后的后摇。

## 实现依赖与生产数量

| 顺序 | 必做内容 | 产物 / 边界 |
| --- | --- | --- |
| 1 共用底层 | 稳定定义/实例 ID、11 家族枚举、时间状态机、攻击 ID/子命中、护甲/魔抗公式、韧性与防连续硬直 | 数据结构和调试可视化；当前 Canvas 原型需明确迁移接口，不能只导 JSON 就宣布接入 |
| 2 装备流程 | 两武器槽、一个身体槽、属性重算、拾取对比、替换/丢弃、冷却持久、专注 | 单人真实输入可完成获得→装备→生效→撤下；先用测试柜 |
| 3 近战动作 | 短刀刺切、大刀横扫、单手剑斜斩、重剑劈砸、长枪直刺、戟刺扫钩 | 至少 6 组主攻家族动作；不能继续用同一剑帧仅改变播放速度 |
| 4 远程/施法 | 弩臂/上弦、手枪点射、霰弹肩射、步枪瞄准/点射、法杖施法；弹体、弹丸聚合、衰减、装填 | 5 个远程/法杖家族主攻姿态；三种法杖元素弹体/技能各自可识别 |
| 5 内容扩充 | 33 把外观/图标/手持与掉落图、33 个武器技配置，12 套防具外观/图标/特性 | 武器技可以复用动作片段但须有差异；不要将33件统计为33套整人动画已完成 |
| 6 集成与调平衡 | 掉落来源、中文描述、音量、特效遮挡、敌人韧性、混搭、防重复触发、死亡重开 | 实跑报告、短证明视频、人类试玩反馈；随后再确定经济和内容投放 |

首轮内容需求为 **33 个武器定义、12 个防具定义，合计 45 个物品定义**。图标、掉落图、持握图可由同源作品派生，但必须记录导出版本与状态；不能用一个图标复制 33 次充当剪影差异。基础主攻有 11 个家族；施法、刺扫、举剑及持枪并不适合全部共用一套身体动作。

建议先用 Blender 转绘或二维骨骼建立可换武器层：前手/后手持握点、武器轴、枪口/杖头发射点、地面落脚点、前后手遮挡层与朝向翻转规则明确存储。护甲至少四类剪影，每类三套有可识别的护肩/下摆/头颈细节。装甲外观需覆盖待机、行走、11 家族主攻与受击/死亡的变形，不能只有站立预览。

若直接为 12 套防具逐件绘制 11 家族的整人主攻，单主攻就会形成 **12×11=132 组外观-动作组合**，尚不含裸装、武器技、走跑与受击；这不是当前已经制作的数量。模块化能降低重画量，但仍须检查这 132 个组合的穿插与持握。没有实际制作速度与美术方式依据，本轮不编造人天、交期或预算。

## 待执行的验收场景

| 关注点 | 可重复场景 | 通过条件 |
| --- | --- | --- |
| 家族区别 | 同一无甲木桩、同一朝向，依次用11家族主攻；再把3敌人错开纵深 | 长枪窄长、小刀短快、刀扫宽、重剑强承诺、射击/施法循环可见；录像与配置中的起手/落点一致，不能只靠UI名称识别 |
| 近战边界 | 标注每把射程、最小距离和Y半宽；木桩中心分别放在各具体形状边界内外1cm；跳跃高度差64/66cm | 椭圆扫/矩形刺/分段形状分别正确，外包络角落不能误中；杆内盲区遵循条目，影子与VFX不篡改判定 |
| 多段 / 散弹 | 一次短点射、多段斩、霰弹近端全中、仅一丸中；标准受击体18×16cm半尺寸与更大靶子对比 | 名义伤害按定义合计，多段有独立子ID，一挥不重复扫血；霰弹同tick聚合，受击体影响丸数但不能越过中心硬边界，不因先中一丸吞掉其余丸 |
| 装填 | 打空、半弹T装填、装填99%取消、切枪/丢弃后拾回 | 完成才补弹；取消无收益，切换不重置冷却或绕过动作；无限备弹显示明确 |
| 专注 | 100耗至不足、恢复等待、切枪、换袍、受击打断施法 | 不足不能射；时序/返还符合规则；换装不回满、不重置技冷却，没有免费连发 |
| 盔甲数学 | 对12套各输入40物理/40魔法；比较空甲，换甲后再测 | 浮点结果符合对应公式与60%上限，旧属性移除，单次伤害来源没有重复减伤 |
| 速度与韧性 | 重甲+重剑与轻甲+小刀，测1s逻辑移动；连续打击韧性40木桩 | 防具×武器倍率正确；削韧达阈值才中断，保护期内受伤但不无限硬直 |
| 特性限制 | 对每个触发特性连续攻击/卸装/拾回/同时触发 | 条目所述冷却/条件只触发一次，不由额外伤害递归触发，不通过换装刷新 |
| 装备归属 | 双槽满换武器、穿甲被打断、堆叠掉落、出口旁拾取、死亡重开 | 同一实例只在一个位置；无复制/丢失；E先明确拾取对象；死亡恢复开局 |
| 可读性 | 1280×720基准下3敌人战斗、火焰/散弹/袍摆同时出现 | 仍看见脚下影子、敌人预警和受击来源；前后遮挡/左右翻转/枪口正确 |
| 组合规模 | 自动枚举33武器×12甲，再加无甲33，检查属性；逐家族采样动作 | **429 个装备属性组合**没有非法值或属性残留；不能用静态枚举代替人类动作手感验收 |

设计阶段只检查数量、字段、数值自洽和描述一致；边界命中、状态触发、听感、重量感与平衡均需运行游戏。量化数据不足时记录缺口，不能把“设计合理”作为“实际好玩”的证明。

## 不在本轮范围但仍保留的工作

完整消耗道具/投掷物/被动道具、普通/精英敌人和首领、地牢投放、商店经济、品质词条、强化、存档与合作均继续保留在需求台账。武器设计中的用途不等于某个敌人已经被设计或制作。后续先以武器的纵深覆盖、破韧和射程形成敌人应对设计，再安排道具联动，避免另做一套不兼容的数值规则。
