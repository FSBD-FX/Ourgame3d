# 近战武器设计 v1：六个家族，十八把

日期：2026-10-12。状态：**原创设计稿 / design_only；未接入游戏、未试玩调平衡**。本文件与 [共同规则](00-共同规则.md)、[结构化近战目录](weapons-melee.json) 配套，数值是制作起点。现有剑、斧原型保留；这里的单手剑仍是待制作定义，斧不计入这十八把。

## 读法与共同边界

- 所有距离是地面逻辑 cm，纵深为 Y 半宽，完整宽度是其两倍。动作时间从按下主攻或武器技起算；主攻与武器技各自完整结束后才能接下一个动作，武器技不取消主攻后摇。
- 主攻 J / 左键，武器技 K / 右键；这些武器均不消耗弹药或专注。近战仅地面使用，当前原型的跳跃攻击不能直接视为本目录的已完成功能。
- 每击的伤害与削韧是两套量；只有达到敌人的韧性阈值才触发共用硬直，保护期内仍受生命伤害但不累计削韧。多段使用独立子命中 ID，不能复用旧的逐击强制硬直。
- 主攻前摇前 40% 可用反向移动取消且不伤害，之后锁定朝向；主动窗口和后摇不允许跳跃取消。走位按表中攻击移动倍率，再乘身体防具倍率；受伤等动作限制按共同规则取值。
- 近战位移技只沿明确方向移动、受阻即停，不穿人、不越墙、不吸附、不额外无敌；推拉普通目标最多 40 cm，Boss 不位移。命中停顿是本地表现，不暂停逻辑时间。
- 范围表给出前方最大外包络。枪的空区、戟的分段形状、铸潮的内外沿、最近目标限制必须按条目实现，不能把所有外包络统一做成满伤长方形。

**几何统一约定：**使用目标地面逻辑中心，不额外扩张目标碰撞半径。`AttackerFacing` 为朝右 +1、朝左 -1；`x = (TargetGroundX - AttackOriginX) × AttackerFacing`，`y = TargetGroundY - AttackOriginY`，R 为该段前向距离、D 为该段纵深半宽。横扫、斜斩、返斩、横拨与钩斩使用前半椭圆：`(x/R)^2 + (y/D)^2 ≤ 1` 且 `minRange ≤ x ≤ R`；直刺、锥刺、枪撩刺、剑顶、杆尾顶、重剑窄劈或砸击使用矩形 `[minRange,R] × [-D,D]`。武器技未写空区时 minRange=0，明确写出的分段距离和空区优先；戟每段独立选择矩形或前半椭圆，倒钩回钩捕获段为明确注明的矩形。所有形状仍须满足各条目高差、最近目标及命中次数限制。

**镜像推拉约定：**推离统一为 `ΔX = AttackerFacing × 实际推离距离`，拉近统一为 `ΔX = -AttackerFacing × 实际牵引距离`；实际距离取条目上限与可通行距离的较小值。向左攻击时方向相应镜像，不能把推离固定为世界 X 正向；Boss 不发生推拉位移。

单段攻击在整段有效窗内逐帧检查，按该次攻击 ID 保证每目标仅一次；多段攻击的各个 t 是各子窗口起点，本文件逐条给出 0.04 s 子窗口，每子 ID 每目标至多一次。帧间时间跨过子窗口时也必须做一次时间扫掠检查，不能只在时间恰好等于 t 的一帧采样，避免低帧率漏击；子窗口间的收杆、换握或转腕不产生伤害。

## DAO · 大刀

## 制作与验收要点

这些是后续实施要求，当前没有把它们标为通过。

1. **动作识别：**把武器贴图暂时改成单色，仅看身体姿势和攻击轨迹，应能区分短刺、宽扫、重劈、枪刺、戟的换握。三把同家族至少通过主攻节奏或武器技动作辨识，而不是依赖装备名称。
2. **范围真实：**各放置正前、纵深边缘、背后、贴身、高差超过 65 cm 的测试靶。长枪与长戟空区应落空，单手刺剑的最近目标截停应有效，刀光不能扩大实际判定。
3. **分段真实：**燕尾、折锋、双脊、巡门等先命中首段、再让靶移开，必须只扣首段伤害；每段不得重复命中同一目标。巡门 175–215 cm 远端只中刺，半握月戟 110 cm 外只中第一扫。
4. **区域收益：**铸潮在 119 cm 与 120 cm 边界分别结算内侧 28 / 18 和外沿 42 / 30，单次不叠算。破缝主攻仅本次按 75% armor 减伤，武器技用完整 armor，切换武器后目标护甲不改变。
5. **防连续控制：**裂碑跨过普通示例阈值后，保护期内第二次攻击照扣生命但不再次硬直；双脊两次子命中也遵守保护规则。削韧、生命无敌帧、表现停顿不能混成一个计时器。
6. **位移边界：**跨步、退刺、牵引在敌人、墙角及房间边缘受阻即停，不能穿人、拉 Boss、改变跳跃高度或绕过未开放的房间出口。被牵引的目标仍可能攻击，不额外清空其招式。
7. **动作代价：**首段命中后不能跳跃或切武器取消后摇；攻击移动须按身体防具倍率乘算。快速小刀不能抹掉双击承诺，重剑也不能在起手完成后自由转向。
8. **资源与资产：**十八把无弹药与专注消耗；不增设暗中耐力消耗、耐久、随机暴击或隐藏背刺。按六类动作骨架、各把专属武器技及持握转换制作，武器图层与身体动画对齐；现有共享剑/斧帧不满足所有类别动作。

本文件完成的是可供制作与核对的近战定义。数据驱动加载、武器槽、K 武器技、独立碰撞形状、破韧保护、位移碰撞、专门动作、音效接入与实际试玩，均需后续完成。
