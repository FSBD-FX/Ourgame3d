# 石像与森林主线Boss设计 v1

日期：2026-10-13；模块：D-06；来源事件：EV-024；状态：**助手设计初稿，未制作、未试玩、未逐条确认**。本文件与 [结构化数据](stone-forest.json) 对应，2名地面主线Boss、8招。章节顺序、名称、属性和数值均为助手建议；世界观归属留待D-10。

## 事实、推理与风险

事实：用户已经指定石像、树人等敌人类别；当前战斗设计采用XY地面移动、独立Z跳跃、没有通用格挡，最短小刀攻击距离为88cm。已有原型尚未实现这些Boss。

推理：首个Boss用直线冲阵、横带和椭圆，让玩家练习“识别警示—沿Y避开—恢复期反击”；第二个Boss再区分锁玩家落点与固定直线射击，二阶段只加一个完整新招，便于看出变化。

风险：身体过宽会让小刀攻击不到；锁点过晚会逼玩家依赖闪避；场边/前景会遮住Y出口；多段总伤害容易重复相加。下文分别限制身体、50%锁定、地面步行出口与明确子段。场地建议不是可达性证明，仍需D-07几何和D-14试玩验证。

## 两名Boss共同约定

- 数据采用 [Boss共通规则](common-rules.json)，不套普通敌人/精英增幅，也不随玩家天赋实时补强。身体无未声明接触伤害；无随机暴击、第二血条、召唤和残留伤害地毯。
- 半血只排队切阶段，当前招或中断后的完整恢复结束后显示1.20s提示。期间可受伤、可破韧，不回血、不无敌、不清CD；提示和受控时钟互不抹除，两者结束后才可起下一招。
- 破韧受控0.25s、保护3.00s；寒缓幅度减半最高12.5%/2s、电震目标间隔4s、燃烧最高6/s持续3s。推拉位移免疫，但伤害和削韧保留；界面显式显示Boss抗性标识。普通大型与精英不因此获得Boss抗性。
- 起手接纳时计CD，中断不退款。全部招在前摇50%锁定，之后不转身、不追Y；每招后摇至少1.90s且原地不转身、不移动。前摇/有效期破韧则0.25s硬直后执行完整声明恢复；恢复中破韧不重启恢复，下一动作取原恢复截止与硬直结束较晚者。死亡只停止源和未发段，同点已到期伤害仍全量结算，玩家存活且成功提交后才清本Boss剩余场上攻击；失败按本局结束清理。既有角色状态、next_tick、CD及资源不被该攻击清理删除。
- 近战/范围按目标地面中心精确形状、实际高度与LOS判定，不能把特效包围盒当伤害；所有本稿地面招Z0/容差65，种弹实际枪口Z28/容差65。直弹扫掠独立受击体，同时仍须过实际枪口原始射程、固定Y硬界。
- 单次攻击ID及每显式子段分别去重。无子段的招只命中一次；双冠根刺仅两个22点子段，44是合计说明，不能再额外结算44。
- 建议空场半X1000/半Y450cm、地面连续可走，无小怪和遮挡警示的前景。场边起手条件必须保留一侧合法Y逃逸，不可仅因纸面攻击宽度小于场地宽度就认定安全。
- 地面逃逸压力基准为265×0.65×0.75=129.1875cm/s，包含v2最低待机移速和25%残留寒缓，再预留0.15s反应时间及1cm余量。八招均需满足 `(前摇/2−0.15)×129.1875 > 所需Y位移+1`；这里只是开阔平地算术，不证明场边、身体绕行或玩家当前不可取消动作下必能避开。

建议第一大关主线Boss。与普通石像骑士的区别是：有直冲、正面横带、全周地震和二阶段偏前落印四种空间问题；不会靠增加血量复制普通骑士的两招。

冲阵预警必须显示整个直线路径，而非只在脚边闪光；锁后地面提示不再跟随玩家。命中、冲空和撞墙均给完整2.20s恢复，不允许命中后跳过后摇接盾踏。半血冠裂变亮是阶段提示，不等于新生命或防御倍增。

## 素材拆分和后续验证

两套基础骨架及武器/枝荚分件、各自待机/走/出场/4招/受击/破韧/死亡动作、二阶段材质和警示即可表达本稿；**不是8套独立Boss，也不代表素材已制作**。重刃/树枝视觉、石像裂冠、双冠根纹均不能暗增受击体、伤害或属性。

| 未来验证 | 通过条件 |
|---|---|
| 全武器基础可打 | 最短88cm小刀在身体不重叠时可命中；近战无需特定掉落 |
| Y反制 | 每招锁后存在合法地面出口，不靠消耗品/闪避/跳跃；场角出生及被边缘挤压也检查 |
| 恢复窗口 | 命中、失手、撞墙、中断均保留声明恢复；无隐藏转身/平移或phase取消 |
| 半血和同点死亡 | 过阈值只排队；提示可伤可破韧，致死直接死亡，不回血/多领奖 |
| 双点去重 | 单子段不连帧重复；两个22可各计一次，不能再额外计44 |
| 种弹硬界 | 枪口来源、630射程、Y±26、实际Z28与hurtbox扫掠同时合法；友军挡不伤 |
| 原子CD与中断 | 起手立刻计CD；破韧/死亡未发段不生成，未发预算清理，不返CD |
| 警示可读 | 镜头含完整路径和地面印，前景不遮，静音仍能识别锁定和先后顺序 |

当前交付只覆盖纸面结构、数值与接口；竞技场实际可达性、动态碰撞、动画、手感、难度和耗时均待制作后验证。
