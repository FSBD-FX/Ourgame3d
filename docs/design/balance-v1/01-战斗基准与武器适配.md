# D-14 战斗基准与武器适配设计 v1

日期：2026-10-14（Asia/Shanghai）；事件EV-032，用户“ok”。`design_only`，`runtime_implemented=false`。本文与新增章成长均为助手提案，未逐条批准、未实机验收。

## 事实、推理与风险

**事实。** 只读目录中有33武器、11家族、12甲、28基础敌、9精英变体、65独立敌招、7Boss和27Boss招。伤害与时间读取原JSON，不从名称/图稿估算。D02/v2已取代早期v1“无暴击/地面才可主攻”的旧表述；现在玩家基础暴击5%、倍率1.5，离地一次主攻，技能仍限地面。当前参考算术刻意选“不发生暴击”的确定性场景，没有把真实规则改为0%暴击。

**推理。** 合理比较需要分开一次主攻、弹匣+装填、专注停耗恢复、实际形状与可用反击窗口。`damage_total`已经是第一目标完整主攻名义总额：不能再乘弹数/子段数，也不能把穿透第二目标加回同一个目标。此版建立可复算离线算术，不修改任何旧数值，不把表格排行当武器强弱结论。

**风险。** 所有吞吐忽略真实命中率、走位、Boss出招强制空档、遮挡、受伤/破韧、失手和输入间隔；按说明还排除暴击、附魔、道具、遗物、技能和持续伤害。木桩致死事件时间是静止、不断受击且不还手目标的理想算术，不是Boss实测TTK、整局时长或公平认证。零天赋可通关仍仅待试玩目标。

## 专注持续性
