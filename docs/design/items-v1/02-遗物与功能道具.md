# D-03：局内遗物与功能道具 v1

2026-10-13，Asia/Shanghai，承接EV-021“继续”。**原创助手方案、设计初稿，未制作/未试玩/未逐条确认。** 本目录含8件被动遗物、6件功能工具；所有数量、属性、时间、百分比和预算均为已填的建议参数，待试玩调整，具体结构化数据见[passives-and-utilities.json](passives-and-utilities.json)。

## 1. 事实、推理与风险

**事实**：已有33武器/12身体甲和属性附魔v2；D-02已定义自由装备、闪避、空攻和完整动作。用户要求局内用金币强化、局外用收集物成长/解锁。没有逐项指定本目录道具名、槽数、数值，也没有完成道具运行系统。

**推理**：被动遗物负责改变本局取舍；功能工具负责路线与设施机会。前者占有限战斗构筑槽，后者进入独立随身栏，可避免钥匙挤掉回血药或把所有奖励都变成攻击加成。

**风险**：多层独立乘算会绕过附魔上限；安全房反复换HP/治疗遗物可能制造免费恢复；击杀触发若无归属/预算会鼓励刷召唤物；功能券若不检查实际设施可能产生无法使用的稀缺奖励。本文将这些边界写入使用规则，来源权重/价格/掉落经济仍由D-08完成。

“被动遗物”是本局装备式道具；“遗物碎片”若作为局外货币暂名，是另一种资源。两者不能叠成同一物品，不能卖出遗物直接取得局外收集物。

## 2. 被动遗物共同规则

- 初稿设3个遗物槽，每槽一个不同ID，背包/地面不生效；同ID不能重复叠加，不合成升级，不默认附魔。取得同ID只允许保留已有或交换物理实例，不增加战力。
- 仅清房安全、地面站定时E交互0.50s装备/替换；提交前旧遗物有效，移动、受伤或合法闪避取消，原归属与地面物保持。战斗、空中、攻击/装填/换装和暂停背包内不能提交；可以在安全条件下免费丢弃/替换，无职业限制。
- 遗物贡献与当前武器/身体甲附魔、其他合法临时增益先按同stat相加，最后只套一次v2最终边界。原始v2数据作为历史保留；D-03扩展的是来源范围。没有第二层额外伤害/减伤乘数。
- 继续使用直接伤害[-30,+50]%、动作速度[-20,+20]%、直接削韧[-25,+25]%、护甲/魔抗0～150、韧性30～120、最大HP60～150、暴击率0～20%、倍率1～2、吸血0～5%、移速合计[-25,+25]%及正常倍率0.65～1.25、专注恢复/治疗效率[-25,+25]%等原最终边界。装填速度[-25,+25]%、易伤[0,+25]%同样不扩上限。
- 正负贡献可被其他装备组合抵消，也可被最终边界截断。拾取提示同时展示原始条目和当前实际结果/已封顶原因；不保证每种组合都提供净收益。免费替换不自动消耗付费服务。
- 装卸不治疗、不回专注、不补弹、不刷新动作/触发/武器技/闪避CD；最大HP下降仅向下截当前HP，上升不补。累计削韧保留，下降后的韧性阈值检查沿v2规则。飞行弹沿攻击40%锁定点的攻击者数值快照；治疗效率在实际回复时读取当前角色。
- 本目录7件静态属性、1件有限死亡事件，避免首批遗物同时引入护盾、复活、召唤、永久增益和复杂连锁状态。

选择量级的依据：首批常驻加成保持在v2最终空间的一部分，让现有附魔/后续临时道具仍有组合余量；代价分别作用走位、破韧、动作、火力、治疗或生存容错。`+10%伤害/−6%动作速度`无其他修正时连续理论直接DPS约为`1.10×0.94=1.034`；它的价值主要是每轮收益与破绽规划，不能用+10%DPS描述。装填+15%指时长÷1.15，约缩短13.04%，不把百分数直接从时间减去。

无甲示例：回声棱镜使12/s恢复变13.8/s；薄血契印使最大HP100变90；医者结绳使基础20HP合法治疗变23HP，再截HP/来源预算。它们都是算术示例，不证明完整一局平衡。

### 3.1 肃清徽章死亡事件边界

**目的/体验**：完成真实遭遇推进后得到少量恢复，决定是否用一个槽换清杂续航。**输入**：由玩家武器主攻/武器技直接伤害导致、具有奖励资格的敌人第一次真实死亡。**输出**：满足条件时一次有限治疗。不是命中、霰弹丸数或伤害数字触发。

1. 攻击40%锁定快照须已装备该遗物，死亡结算时也仍有效；旧飞行弹可沿原快照合法结算，不因之后才装备而补资格。
2. 先结算敌人真实死亡，再检查玩家仍存活、Run仍进行、敌人奖励资格、角色同ID CD与当前RoomID预算。同一`RunID+EnemySpawnID`死亡事件只认一次。
3. 符合事件且CD就绪时先启动8s CD，再以即时治疗效率计算`min(2×治疗倍率,本房实际回复剩余额度,当前缺失HP)`。满血仍消耗该次机会/CD，回复0不占实际治疗额度；CD未好不储存待以后治疗。预算耗尽无治疗。
4. 每房最多实际回复6HP，**在治疗效率之后**封顶；这不是吸血，不占v2吸血3HP/attack与6HP/滚动1s的额度。两种合法恢复同一时点先逐源结算，各自去重/预算，最终不超过缺失HP；共同先判断存活，不能在死亡结算后复活。
5. CD/预算挂角色本局、遗物ID、原RoomID，暂停冻结，离房再进/装卸/换武器不刷新。满房治疗次数有限，不能靠保存退出重复领。
6. DoT、道具、陷阱、友军/环境击杀、自伤、物件、脚本清除、召唤/无限增援、复活/复制的重复死亡均无资格。敌人是否来自奖励预算遭遇由D-05/07显式给标记，未配置默认不触发。不会因为每个召唤物有新SpawnID就合法。

失败状态：玩家死亡、终局已锁、资格不合、已结算或预算耗尽均无治疗；不延迟奖励、不转换金币/收集物。不发生治疗也不重新寻找“下一敌人”转移同一死亡事件。未来运行验收应特别覆盖同帧双方死亡、霰弹群杀、旧弹、满血CD和召唤刷怪。

### 4.1 服务共同规范

**目的/体验**：工具让玩家选择把有限便利用在哪里，不能让地图运气封锁主线。**输入**：清房、安全地面、匹配对象，预览后确认。**输出**：一次原服务、一次工具消费、必要剩余金币/成本变化。功能工具CD0表示交互事务本身无额外冷却，不代表可以连续重复同一对象；依然有堆叠、对象状态与次数限制。

- 展示原服务、使用哪张券、原价/折后价、明确结果或原有随机风险、剩余费用；不自动把钥匙/券用在最近物件，不在背包暂停里跳过战斗提交。
- 单次服务最多本目录一件工具，不叠折价/代付券，不找零。工具不是金币或局外收集物，无卖出/兑换/拆解。正常奖励仍要按D-01真实完成战斗/探索取得。
- `校验工具数量、对象实例/版本、资格、剩余成本→一次性提交扣工具/扣必要费用/服务状态→持久记录`。校验失败不扣；重复确认同事务不双消费或重复产出。随机轮盘仍按D-01固定本局随机流，显示结果后不能退出退券重抽。
- 原服务的等级/次数/章节/解锁限制全部保留；工具不生成免费新装备，不刷新商人，不复制附魔，强化/洗净不回复HP/专注/弹药或冷却。
- 掉落前按已解锁服务/实际可匹配路线过滤。若D-07/08不用路线碑、普通轮盘、0→1基础工序等接口，对应工具退出来源池；没有匹配对象时不占稀缺奖励位。过滤不替代使用时重新校验，因为玩家可能后来已消耗次数/升级装备。
- 每局来源数量、券折算金币价值、一次服务费用和路线上限尚未确定，D-08必须把“免一次”作为实际金币节约进入经济模型，不能当作无成本奖励。

折价20%是让玩家仍需支付大部分金币的起始假设；最多2票限制囤积。通用钥匙3把给出当前用/后面用的选择，而不会无限囤钥匙。轮盘券、路线图、初锻券、洗净券各1限制服务绕过的规模；这些上限需要与整局来源数量一起校准，尚无足够运行数据证明优劣。
