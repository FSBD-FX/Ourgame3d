# 键鼠、手柄与输入边界设计初稿

2026-10-14；D-11；来源EV-029。映射、死区、按键上下文与重绑细节均为助手提案，未实装/未接UE验证。数据见[input-rules.json](input-rules.json)，继承[D-02角色输入](../player-combat-v1/player-combat-rules.json)、[D-03道具优先级](../items-v1/common-rules.json)与[D-04交互](../inventory-v1/inventory-rules.json)，旧源保留不改。

## 事实、推理、风险

事实：D-03待机输入优先级为闪避、跳跃、道具1、道具2、技能、主攻、切换、装填、交互；D-04明确UI-02/07/08为不暂停实时浮层。世界方向键能移动，但在这些浮层方向键只导航，不能一次事件同时移动/选槽。Enter新按确认，Esc取消；已开始真实动作不能借关预览取消后摇。

推理：手柄用位置键South/East/West/North表示A/B/X/Y，再由设备显示相应图标；实时层统一View纯取消，四向十字全留给导航。South在UI只确认，East默认只有合法闪避才关闭执行。这样明确区分“我要取消”和“我要躲开”，不用同一非法闪避意图偷偷变成取消。

风险：预持按键、上下文切换、触发器噪声、确认/跳跃重叠与重绑后的固定UI遮蔽容易造成误扣费/误出招。需要对每一上下文验证所有权与释放门槛；纸面映射不能证明所有真实手柄驱动都兼容，也不代表死区/重复速率已试玩调好。

## 世界优先级与移动

世界动作继续闪避→跳跃→1→2→技能→主攻→切换→装填→交互，从当前合法请求中只接纳一个。装填中继续闪避→切换→T/RB取消装填；同一步取消后J/K不能顺带出招，须后续新按。装填完成同点先完成再处理新请求，取消不补弹，不触发空弹自动重装。

W/D等是连续移动，离散战斗/交互必须新按，不新增按住连砍、连喝、E缓冲或万能动作队列。保留D-02主攻最后0.12秒后摇一个缓冲槽，其余照旧；所有UI/暂停切换清攻击/道具缓冲，不倒退已接纳攻击时间轴。J和鼠标左键同一步只是一个primary、一个AttackID。

左摇杆取8方向，初稿径向启动死区0.22、释放/回中0.18，越过死区按完整移动意图，不加慢走。八扇区45°，对角向量归一化；W/摇杆上是纵深Y远向，不是跳跃Z。原出招/空中/受伤/寒缓约束仍在底速后应用，闪避185厘米/.4秒、跳高与无敌参数不改。LT/RT按按钮使用：≥.55新按、≤.35释放；一直压住不连用。右摇杆和摇杆按下默认未绑定，不增加瞄准、镜头或冲刺。死区/阈值尚待真设备验证。

## 实时浮层UI-02 / UI-07 / UI-08

这些状态不暂停世界。选择尚未提交，目标ID/报价/库存/容量/安全仍在最终确认时重验；方向键导航不能重选世界邻近对象。

| 输入 | 实时层所有权与结果 |
|---|---|
| 键盘方向键、Tab | 仅界面导航/焦点；不移动、不切世界目标。导航与确认同一步，只导航，确认丢弃须新按。 |
| 手柄十字四向 | 全部仅导航；十字↑不再交互，十字→不切世界目标，十字↓不取消。 |
| Enter / South(A) | 新按确认所选明确操作，UI消费；South不顺带跳跃。打开浮层的同一次按下或同一步其他按下不算确认。 |
| Esc / View | **纯取消**未提交预览；View不同时开地图。再次世界View地图需先释放再新按。 |
| 默认East(B) | 新按且闪避合法：关预览并接纳一次闪避；闪避非法：消费、显示原因、保留浮层，不能偷变纯取消。 |
| 默认West(X) / North(Y) | 新按合法主攻/技能：关预览并接纳一次；没有合法请求时保留浮层，不自动变别的动作。 |
| 默认LB/RB/LT/RT，键盘Shift/Space/1/2/K/J/Q/T | 不被UI占有的当前映射按D-03合法优先级关层执行一次；手柄South已属确认，因此默认手柄不能靠同键确认又跳。 |
| 新WASD或新左摇杆移动意图 | 关层并把新移动向量交给世界连续执行；预持方向须先释放/回中，不能关层后突然自行移动。 |
| Menu / 键盘I/M | Menu取消预览后开暂停；I开暂停检视、M开只读暂停地图。手柄十字←仍导航，View仍纯取消。 |

顶层视图请求先处理，然后纯取消，再处理新移动与最高合法世界逃离请求，再单个导航，最后新确认。若同一步既有合法闪避又有South确认，先逃离，不提交购买。非法East本身不关层；同一步另外独立合法请求仍按所属上下文处理，不能把非法East“解释”为那个请求。

鼠标先命中UI：明确确认按钮只确认，选项行只选，不在同一点击买入；点面板空白被消费。实时层外点击若关闭预览，只作纯取消并消费这次点击，不能变成同次主攻/技能；松开后在世界重新点击才可出招。点击按钮、面板或滚动区都由UI消费，右键也不穿透成技能；暂停面板外点击不产生世界动作。悬停不交互、不提交、不改世界目标。

已经进入UI-03真实拾取/换装/购买动作后，按D-04移动、有效伤害或合法闪避等中断与恢复规则执行；关一张纯预览不能取消真实后摇、撤销已付款结果或刷新资源。

## 暂停、检视、地图与执行整理

检视I/十字←、暂停Esc/Menu和世界M/View地图都冻结同一本局模拟时钟。暂停界面的十字/摇杆/方向/WASD只导航；South确认，East返回并消费，绝不恢复后顺带闪避。地图只看合法已知路径，不因打开而揭示未发现H01；View/East/Menu或M/Esc关闭也消费，不改镜头/世界目标。

UI-04战斗检视只读；UI-05安全检视可预选一个整理意图；UI-06只有新Enter/South激活**返回游戏并执行**才保存意图并恢复后重验真实动作。I/Esc/View/Menu普通关闭不执行。关闭时其他玩法键已按住，或恢复时有新玩法输入，则清计划；失败不自动等安全/重试，不回滚真实计时/伤害。界面确认只选择明确按钮，不能绕D-09“有未结束局不能局外升级/退款/新局”的锁。

## 预持释放、重绑与设备事件

上下文开启/关闭消费所属事件、清缓冲。当前已按住的战斗按钮或未回中的世界移动轴进入未武装状态，须释放/回中后新按才接受；打开服务的十字↑继续压住不能立刻开始向上连选。唯一例外是已合法交给世界的**本次新输入**：可执行一次已接纳动作，新移动交接后的向量可正常持续，不应下一步又被强制清零。其他旧预持仍须释放。导航可在新按后延迟.35秒、每.10秒重复，确认/取消/道具/主攻不重复。

首稿固定UI导航、确认、取消角色；世界动作可重绑。检查必须展开世界、实时层和暂停层，而不是只检查世界按钮是否重复。已知默认别名（South跳/确认、十字↑交互/导航、View地图/取消等）明确按上下文隔离；其中默认E在世界交互、在实时层消费且不确认或二次交互，默认鼠标右键在世界技能、在实时层由UI消费或点层外纯取消，这两条是显式默认例外。新把主攻绑定View等会被实时固定UI遮蔽的配置应拒绝并解释。自由输入区域按当前映射解释，所以若合法把闪避改到RB，实时RB会走闪避，不能仍硬编码East闪避；暂停East仍只返回。

冲突只允许取消保旧，或预览所有受影响行后原子交换且再次通过全上下文校验。不自动解绑另一个动作；不移除必需动作最后一个合法入口，必须保留至少一条实时直接移动或合法闪避逃离路径，并有独立纯取消在闪避冷却时可用。只用方向键移动的键鼠玩家，可先Esc纯取消，再释放并新按方向键回世界移动；不能把WASD当唯一逃离方案，也不能重绑掉所有离层路径。固定UI冲突不能靠悄悄丢掉按键来解决。恢复默认也明确确认整份选中设备配置。捕获界面的Esc/East只取消，不绑定为战斗动作；不增加长按、双击、连招或组合键语义。保存设置版本由D-13设计，当前未实现。

单人只一玩家槽，键鼠和一只分配手柄合成同一事件流；不因插入手柄生成第二玩家。图标随有意新按/越死区移动切换，噪声不切，初稿.15秒显示防抖不延迟玩法输入。当前使用的手柄断开时清该设备按钮/轴/缓冲并显示自动暂停；只是旁边闲置手柄断开则通知、不强停键鼠游戏。失焦在单人活动局也自动暂停，已到期伤害/死亡和已有动作提交先按原顺序处理，不能借失焦撤销。

重新获得焦点或重连不自动恢复：先释放/回中，再新按明确继续。真实进行中动作只冻结剩余时间，已提交事务保同记录，不退款/重抽/补HP或弹药；纯预览和未执行整理意图丢弃。若已提交转场期间发生设备事件，完成同一转场后在目标页保留暂停原因，不再扣门票或造新RunID。多人断线/暂停策略不由本单人方案擅自决定。
