# 新手引导与复习设计 v1

2026-10-14，Asia/Shanghai；D-11；EV-029。**助手提案，未制作、未试玩、未验证真实学习效果。** 数据见 [tutorials.json](tutorials.json)：30条通用说明、10条区域威胁说明、5个区域组、13个未来验收案例。它们是可复习的说明条目，数量不代表额外关卡、教学分钟数或必须完成的任务。

## 事实、推理与风险

事实：D-07每章已有N01入口与N02教学节点；N02最小清单是一名普通敌人、一组、威胁不超过4，候选敌人列表不代表全部同时出现。D-02/03/04已有完整动作、资源、携带与安全规则；D-08到D-10已有经济、成长、故事和跳过边界。

推理：先帮助玩家读懂当前画面，再在自然拿到相关武器/道具时说明使用条件。未拿到第二武器、枪弩、法杖或药瓶，就不出要求切换/装填/施法/喝药的操作考核。五区域说明只绑定实际出现的敌人，不为讲完目录增加演员或波次。

风险：教程暂停下一波、赠药、无敌或假清房，会让练习规则与正式游戏不一致；同一键关闭提示后穿透成攻击/购买，会制造误操作；把“说明已看”算成“操作学会”，则无法区分帮助状态。以下将提示呈现、实际操作证据与权威游戏事实分别记录。

## 1. 可以全部跳过，正常路线保持成立

所有教程可关闭、可跳、可在帮助索引复查，不阻主路、出口、商店、动作、剧情事实或正常结局。没有教程专属房、练习假人、新敌人、额外奖品、免单、额外物品、无敌或伤害保护；也没有“先喝一瓶/花一次钱/转一次轮盘才能出门”的条件。

首次开始新局可见短说明；入口N01提供地面移动与帮助入口，不另生成敌人、机关或跳跃门。零敌房不会清除角色燃烧等状态。进入N02以后，实际战斗沿既有manifest、苏醒、攻击与波次时钟运行；教程只观察事件，不决定是否接纳下一组。

默认同时最多一条自动提示，每课每RunID最多自动展示一次；这些次数是本轮UI提案。没有要求必须等几秒、读完几行才继续的系统计时。当前情境失效时收起旧提示，不能稍后突然把过时的装填/拾取提示盖在新威胁上。用户主动复习次数不限，关闭教程也不关闭敌人预警、费用、失败原因或风险确认。

## 2. 战斗短提示与主动长说明

实时提示采用非模态短句，不抢输入、不暂停、不改时间倍率、不取消当前动作，也不自动打开菜单。真正的死亡/结算、攻击/显现预警、状态警报和交易失败原因优先；如果提示会遮住攻击者、地面范围或出生点，就延后或隐藏提示。

长解释由玩家主动进入检视/帮助页；暂停沿同一本局模拟时钟冻结攻击、投射、DoT、CD、专注恢复与D-07时序。战斗中仍只能查看，不能借说明页换装或用药。关闭后沿D-11输入隔离要求释放旧键，不把关闭UI的操作送进世界成为攻击、闪避或交互。

所有键位文字使用语义占位符，例如`{primary}`、`{dodge}`、`{interact}`、`{item_slot_1}`；由当前设备与绑定解析成按键图示和可读动作名，不在文本写固定AB或默认键帽。改键、切手柄只刷新显示，不发动作、不标记已实践。未绑定动作显示名称与设置入口，不能要求玩家按一个不存在的键。

威胁观察只记录真实事件，例如锁线攻击结算时玩家已在Y带外、骨盾开放恢复实际出现、石蝠实际低位恢复被观察到。没有受伤也不需要为了获得“学会”标记故意挨一下；站位成功不表示所有后续招都掌握，更不改敌人韧性、伤害或下一招选择。

## 5. 提示已看、实际实践、剧情事实各自保存

| 状态 | 写入依据 | 不代表什么 |
|---|---|---|
| 未查看 | 尚未实际显示或打开该说明 | 不表示动作未解锁 |
| 已查看说明 | 真正显示/打开了该条说明 | 不表示已经执行操作或理解全部规则 |
| 已跳过提示 | 玩家关闭该课自动提示/显式跳过 | 不补成已实践，不阻继续 |
| 已实践 | 权威动作/效果事件出现，并记录证据类型 | 不表示熟练度、通关条件或付费成功必需 |
| 已观察机制 | 真实敌招/恢复/后续组事件出现 | 不表示玩家已掌握对应动作 |
| 剧情事实/房清/交易成功 | 原D-07/D-08/D-10权威事务 | 不能由教程已读或按了错误键倒推 |

例如装填按钮被拒绝，不记“已完成装填”；必须实际完成原装填并提交弹匣变化。药物前摇被取消不记“已使用”；技能缺资源未发出不记“已施放”。反过来，玩家没看课但自然完成合法操作，也可有实践证据。坏词/价格/经济/故事等知识课只记已查看或已复习，不设“操作学会”标记；不要求实际洗净或购买。区域敌招与未来批次只记“已观察机制”，不能代替动作实践。

重置教程提示历史只清外观帮助记录，不退天赋、不重开房间、清敌人、补货、重抽随机结果或重领奖。继续存档恢复提示游标时不回放操作；账号长期提示偏好/证据与当局已展示次数分别保存。战斗预警不属于可随教程关闭的内容。

## 6. 复习入口与失败后帮助

帮助索引按基础操作、战斗、装备、携带、道具、房间流程、经济、成长和故事分组；所有课都能查，物品未获得时明确“暂无实践机会”，不把内容藏到必须随机捡到才可读。

失败终态后可推荐玩家刚遇到的真实原因对应说明，仍只展示一条短入口，不依次强迫读完积压课。推荐不猜原因：只有已记录的死亡/资源拒绝/容量/目标失效等证据能选对应课；不凭“输了”一律责怪玩家未升级、未买药或未去付费支路。

失败回顾说明本局金币与装备结束、已入账碎片/见闻保留，未拾碎片不补。若本次新增碎片为0，也要显示原账户余额；不把“零新增”误写成“不能购买任何成长”。待续冒险只可查看成长，只有旧局真实终态处理完成后才允许D-09购买/退款/选样品/新局。

故事正文和结局都可跳过、回顾。主线事实由合法Boss成功自动归档，隐藏见闻由原发现点实际安全交互归档；教程消息不另发事实、碎片或成就。看到剧情课不等本局Boss已打完，跳课也不撤销已经取得的事实。
