# 界面流程与装备比较

2026-10-14 · EV-029 · D-11 · 助手设计初稿，未制作、未试玩。本文给出26个稳定屏幕、九设施引用、10条流程和22个未来案例，不增加价格、装备、库存或玩法。结构化目录见[screens-and-flows.json](screens-and-flows.json)，HUD/地图/设置以[hud-and-feedback.json](hud-and-feedback.json)为准，输入以[input-rules.json](input-rules.json)为准；总览为[UI输入与新手引导设计](../../../UI输入与新手引导设计.md)。

## 1. 事实、推理与风险

**事实**：D-04已经区分实时浮层、I暂停检视、真实动作、普通出口与完整安全；D-08/D-09已有设施价格/库存/随机结果/成长事务；D-10对白跳过不取消风险页、不发奖励。本轮只把这些规则变成可追踪的界面与返回流程。

**推理**：同类字段用共用组件，时钟与权限由原上下文决定。实时装备选择保留战斗风险；I给阅读时间，但不能直接换装。确定商品先验整包容量，未知奖留源端托盘。营地外观不替代局外生命周期检查。

**风险**：一次按键穿透确认、暂停预览先截HP、未知开奖退款、带DoT付门费、退出前自动收物、结算重复领奖、假报保存，都会绕过已有约束。确认只开始原合法动作/事务，实际提交才显示获得；未知提交结果先恢复原记录，不重新扣费或重抽。

## 2. 时钟与输入

- **实时**：HUD、目标、比较/选槽、商人/付费确认、源端领奖和出口浮层不暂停。攻击、DoT、CD、恢复照常；源或安全变化立即重验。
- **真正暂停**：I检视、暂停菜单、地图冻结全部单人模拟时钟。比较组件在I里面仍是暂停，不因为共用实时比较字段切回实时时钟。
- **无本局时钟**：已结束后的结算、实际HUB_IDLE营地；账号修改仍须没有未结束冒险。暂停/待续局看成长只是只读，不可买、全退、研究或创建另一局。
- **继承上下文**：设置、档案和非模态反馈明确继承调用方时钟。界面导航/失败提示不暗自恢复暂停或增加额外暂停。

正文用{confirm}/{cancel}/{dodge}/{navigate}/{move}动作占位，设备按键/字形由输入表提供。实时E开层的同次按下不确认，须新按{confirm}（当前键盘默认Enter）；一次输入只消费一次，不同时选槽和移动/跳跃。实时选择层新合法战斗请求可先关层再按原优先级接纳一次，非法{dodge}保留层并说明原因；手柄View或实时{cancel}只关层；键盘M/I及未被界面占用的当前地图/检视绑定先取消预览，再打开暂停只读地图/检视，具体路由以input-rules.json为准。不能把两种设备控制统称为同一个地图键。

动作已经开始后，继续沿D-04移动意图、有效伤害、合法闪避、目标失效等原取消；攻击/跳跃不会新增取消路径，无效闪避也不取消。关闭UI消费所属键、清攻击/道具缓冲；原先按住的玩法键须释放重按，确认/返回不能穿透成攻击或买第二份。

## 4. 装备比较：把取舍分开

| 区块 | 必须能查看的字段 |
|---|---|
| 身份与目的 | 准确名称/实例去向、当前A/备用B/甲；替换谁、旧物整件落哪。基础强化grade0—3及素制/精制/精良/卓越，与附魔none或I—V分栏。 |
| 原招式与资源 | 主攻/武器技的伤害类型、每子段与真实范围；基础与当前最终前摇/有效/恢复/完整周期、距离/纵深/高度；当前弹匣/上限、基础与当前最终装填时间（含来源和cap），或专注成本/恢复等待；技能剩余CD。DoT/状态单列。 |
| 原始词条 | 每个正负词的方向、极性、原数值与法定区间，固有特性/技能保留；不靠红绿或正负号替代好坏说明。 |
| 实际组合 | 基础/锻造/天赋/遗物/当前手持武器与甲/临时状态贡献；来源合计未截顶值、最终值、本次实际差异，以及封顶/不适用原因。 |
| 角色后果 | HP上限与当前HP、防护与对应减伤、韧性、移动、动作速度、暴击/吸血/治疗/专注等实际结果；并提示不补资源。 |

采用摘要＋展开页承载完整字段，不用一个总战力数字或“更强”箭头替玩家判断。技能伤害类型、重武器完整动作和枪/杖资源分别比较，不把多段、DoT与一次直伤粗暴合成必然DPS。

替换备用B时，当前A继续有效；物件自身比较与角色当前实际变化分开，不能把B附魔误加到当前属性。可另查看切换后估算，实际切换仍走原动作。暂时增益会到期，页面说明预览快照时点与来源，展示当前动作速度影响后的最终时间轴，真实提交重新计算；已有攻击/装填快照与起攻固定时间轴保持。

比较纯只读，不扣费/换归属/截HP/回血/补弹/清削韧/CD。真正提交才从完成后的完整来源算一次最终属性：同上限125、当前120换装后仍120；新上限90才截到90；之后上限升回去也不补血。例子说明公式，不代表新装备属性。重洗/觉醒尚未开奖时只显示原价/概率/当前整套，不伪造可提前选的新结果；确定升阶可显示完整合法后果，坏词也升。

## 5. 两条携带流程

**实时拾取/替换**：HUD明确目标→选槽/比较→新按{confirm}→原0.25/0.35/0.50秒类别动作→提交重验→一次变更。旧物无合法落点、被伤、移动或目标失效等按原规则取消。地面普通栈可部分收取，余量留原地；确定购买是整包全收或全拒绝。当前武器最后一把不能手动丢，货币/剧情旗标不提供丢弃。

**I安全整理**：I暂停看→当前完整安全时选一个整理意图→明确“返回游戏并执行”→恢复先结算伤害/到期→再验安全/实例/数量/落点→真动作结束才变更。普通关闭只是返回，不执行；改选覆盖旧意图，不排队。恢复后有新玩法请求/仍按住其他玩法键或安全变化就清意图，不等自动重试。I不排购买、付费服务或过门，也不免费切当前武器。

快捷两槽显示逐ID冷却与共享使用锁；同ID只补已有栈，满了不能占第二快捷槽。遗物三不同ID展示代价/触发CD/每房预算；重复物理实例交换不叠效果或重置预算。功能物独立计数/上限，只在真实匹配设施由玩家显式选择一件，不默认勾券，不当快捷药使用。

## 6. 九设施与两种奖励

九个真实FAC-ID逐项引用D-08，不复制新价格：FAC-MERCHANT、FAC-SUPPLY、FAC-CHOICE-WHEEL、FAC-ROULETTE、FAC-INTEL-ENTRY、FAC-FORGE、FAC-ENCHANT-PROGRESS、FAC-ENCHANT-REROLL、FAC-ENCHANT-CLEANSE。D-09研究样品只是FAC-MERCHANT原绑定N04的附报价，不变第十设施。

已知普通商品、确定转轮三选一、研究样品都先看到确切整包和全部坏处，再选合法全部去向/旧物落点，验证容量才付费。报价/库存/券版本变化重新预览，当前钱包只需够付，不因其间拾币而单独拒绝。每笔最多一匹配工具；样品现金限制、工票/洗净券合法性照原规则。

未知轮盘或common箱先验空源端托盘及原次数/工具/合法池，原子提交后才显示固定结果。金币同事务入账，空奖没有道具，附魔随机结果直接在原持有装备生效；这些不伪装成待领物。轮盘物品/common箱物品留原源端托盘，一次一件，满包不退款、不重抽、不在地面另生副本；有未领轮盘奖不能再转。结果确认层与托盘领取层均为实时交互层，遵守同一输入消费规则：确认不跳跃、View不打开地图，合法战斗/移动只关闭表现层，已提交结果和未领取物继续留在原源；领取已开始后仍按D-04真实动作取消边界。合法领取才走对应物品容量/动作，离开原房再回仍同结果。不可返回的跨章前提示未领物，确认离开则舍弃且不退币/key、不恢复次数。

每页持续显示原费/实际费、工具、原库存/次数、概率或确定后果。轮盘空奖、门票不等掉落、洗净整套删正负、升阶坏词同升、样品不是赠送，都不能被角色对白/跳过按钮盖住。展示故障若提交状态未知，只能恢复原记录，不宣称未扣款然后重做一笔。

## 7. 普通门与付费入口

普通免费门按全房清、无活敌、落地待机站定、路线许可；不额外要求无DoT或无旧弹。可逆、无遗留/风险的已明确普通门可直接通行；不可返/未知、跨章/结束、地面物/货币/源端奖、房间飞行攻击/部署或身上持续伤害等显示风险页，新按{confirm}。付金币/工具入口另需完整D-04安全，已有付费许可及可选Boss约束也按原规则。

风险页说明不自动收物/出售；离房清掉本房攻击/部署不退资源，身上状态/CD保留，同点致死伤害先于过门。风险/路线/费用实质变化重新展示并取得新确认；同一DoT小数倒计时或同一飞弹位置自然变化只实时显示，不每帧重置确认。新掉落、数量/状态种类/费用/返回性改变仍需要新预览，不能沿旧确认暗中过门。

## 8. 成长、结算、暂停与存续

营地购买/全退/研究/选样品/新局均按D-09真实HUB_IDLE及无未结束局；暂停或待续只看，不改已有局快照。全退预览原有效实付凭据返还，缺失或重复就恢复受阻，不猜当前价或退目录280；研究与样品已购标志保留。

研究页保留14项真实费用/前置/正负效果/来源，强调永久不退和下新局入池不保证出现。样品选择页只选0或1，不发物/扣本局金币；新局提交重验、冻结选择并清账号pending，同一创建重试用原记录。未买下局要局外重选，已买后死亡仍已用资格。

死亡/胜利回顾在原结束事务提交后显示。玩家与Boss同点死亡显示失败，不发未成功Boss奖；已入账遗物碎片只展示，不设重复领取。胜利先完成原永久奖励/剧情事务，不靠点完文本结算。结算页默认焦点是“返回营地”；{confirm}只激活当前明确按钮。结算后R对应{restart_review}只打开新冒险确认，不立即重开；还须独立新按{confirm}并通过HUB_IDLE/当前资格检查。实时装填仍为原T，R不成为局中重开入口。

暂停、设置、地图返回调用方；地图只看已发现拓扑，无传送/揭隐藏。暂停不授剧情安全：不安全时长剧情入口禁用或只列短索引；打开UI-NARRATIVE模态还要完整D-04安全。读/跳对白不发奖、不重设事实、不缩Boss预告。

继续/保存/退出能力待D-13实际接口，UI仅依据权威存续状态。没有持久成功回执不能说“已保存”；恢复未知/不支持时保留记录与未结束锁，不假装新建就是继续，也不开放另一新局。明确放弃沿D-01独立确认结束，不能把关菜单当作放弃。
