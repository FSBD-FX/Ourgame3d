# 房间遭遇时序案例

2026-10-14 · EV-025 · D-07 · 助手设计建议，未制作、未试玩。六个单房模板、36个必需敌人实例、16个组，均不是36种新敌人，也不是固定的正式关卡规模。对应目录为[room-sequences.json](room-sequences.json)，沿用[D-05敌人规则](../enemies-v1/common-rules.json)，D-07共同规则以[common-rules.json](common-rules.json)为准。

## 1. 事实、推理与风险

**事实**：已有普通敌人/精英目录和并发预算；本轮进一步设计明怪、休眠、深入显现、分波和可重叠增援的单房流程。未来组与初始场上实体不能混成一种状态。

**推理**：进入房间就登记有限的必需slot清单，按事件逐组接纳。明怪和预置休眠怪已真实存在；未来入口在接纳前只有清房义务，没有无敌隐形敌人。深入可先锁存，出生仍等依赖与整组预算，因此玩家提前越线、回退、快速击杀都不会漏波或加倍刷怪。

**风险**：休眠不计预算会掩盖围攻强度，前段全灭误判房清会提前开出口，未来暗怪贴身出现会抹掉预警。纸面配额不证明路线和镜头安全；锚点、导航、前后遮挡和低移速走位仍须实测，不能用“几秒必刷/30秒打完”代替遭遇状态。

## 2. 六房共用规则

### 2.1 清单、并发与入口

每房6个必需slot，分2或3组，每组最多3只。slot身份固定为`RunID/RoomInstanceID/slot_id`，保留同一SpawnID直到真死亡；重试入口、苏醒、暂停或回退均不换身份。以下预算按全部基础及精英额外能力取最高职能：小近战1、中型2、远程/支援2、冲锋3、大型4，再加飞行1、精英2。碎刃哥布林、幼株也有投射；盾卫也计支援帽，不能只看名称或主职能。

当前接纳的真实休眠、显现中实体、存活实体和尚未出生的整组预留都占并发，每个slot只算一次；未来未接纳记录只计清房义务。上限仍为actors4/预算8/大型1/冲锋1/飞行1/支援含守盾1/投射敌2/精英1。攻击同时起手与场内2枚飞弹容量仍由D-05独立约束，不能把敌人数合规当成可以同时齐射。

入房有1.00秒方向辨认时间，玩家保留操作、生命、弹药、专注、DoT和CD。敌在方向辨认及自身苏醒完成后，才可开始原本完整前摇；镜头外或看不见清晰预警的单位不能开火。初始预置怪可被提前击伤或杀死，不因为出场流程没演完而复活。

### 2.2 明、暗、深入与时间

- `visible`：初始真实可见实体，计预算、可受伤；不把远处可见但镜头外的怪当成可以偷袭的射手。
- `preplaced_dormant`：初始真实休眠实体，计预算、可受伤/状态，有自己的HP/SpawnID；醒来不重新生成。仅石廊首组使用。
- `future_entry`：接纳前仅manifest记录；没有HP、碰撞、隐藏攻击或掉落。接纳后整组预留，再按入口预告逐只显现。

深入进度为`clamp((玩家连续扫掠地面XY的最大X－入口X)/(出口X－入口X),0,1)`。退回不降低进度，跳跃使用地面投影，门槛覆盖可走Y全宽，不能绕Y或跳过；每次门槛只锁存一次，依赖未完也保留资格。必需门槛必须位于至少一条免费可达路线，不能放到整房清理才开的主出口之后。前段依赖门可以按前组终态开启，主出口仍按全房终态。

串行后组从前组真正全灭起至少喘息2.00秒，且深入条件满足才接纳；不是进入房间第N秒强制刷。若早已全灭并等够2秒，后来越线可立即开始入口预告，不再额外叠一次喘息。唯一重叠模板为机械房，资格由前组剩余≤1产生，同时仍须整组配额合法。

### 2.3 预告、显现与失败

未来组先一次预留整组配额，再选合法入口。预告开始锚点到玩家地面XY距离至少350cm；1.20秒完整声光提示后，实体化时复验至少220cm、导航/非重叠/可见提示/LOS/免费通路。全房新预告起点与实体化分别间隔至少0.80秒。组在A接纳时，第i个slot（从0计）最早A+i×0.80开始自己的完整1.20秒预告，最早A+1.20+i×0.80实体化；不会在A同时亮出所有入口。每只实体出现后至少0.60秒不能攻击，再走自己的原始前摇。石像显现和原生苏醒取`max(0.60,原生苏醒)`，不相加、不缩短原生苏醒。

warning只是提示，没有HP/身体/掉落。整组选择入口时也排除同组其他待显现slot已选的身体占地，不能因为“当前那里还没人”就让三只预留同一点。显现实体站定但已可伤、可施加状态、可被杀；其真死亡是有效终态，不能待显现计时结束复活。显现计时、原生苏醒、入场辨认和当前破韧硬直都结束后，才可接纳原始攻击前摇。已显现slot绝不因同组其他入口失败被撤回或重生。

实体化复验失败不贴身换点、不静默传送：保留该未显现slot身份和未用预留，至少1.00秒退避后选另一合法候选，重新完整预告1.20秒，后续预告/出生间隔照守。已预留却因位置受阻等待6秒时显示备用入口提示；未满足预算、深入、依赖或喘息的合法排队不计这个故障时钟。备用仍须满足同一距离/LOS/预告条件，6秒不是强刷截止。受阻达到12秒按共同规则进入可见技术故障暂停，保留身份/HP/资源/既有奖励，提供修复重试或结束，不伪造击杀/清房；修复事务由D-13细化。当前候选只是一组坐标，关卡验收必须证明至少有可用免费路线和备用入口，不能把永远排队作为完成设计。

普通房地面半X1400/Y450cm，入口(-1250,0)、出口(1250,0)；森林长房半X1800/Y450cm，入口(-1650,0)、出口(1650,0)。六候选锚点为西北/西南(-1050,±300)、中北/中南(0,±300)、东北/东南(1050,±300)。它们仅是局部坐标建议，尚未通过导航或镜头验收，实际选点必须复验。

## 3. 石廊明哨与休眠蝠 · RSEQ-001

| 组 | 敌人slot与状态 | 接纳条件 | 预留预算 |
|---|---|---|---:|
| G1 | S01 石纹哨像`ENM-STN-004`明怪；S02 灰翼石蝠`ENM-STN-002`预置休眠 | 入房提交 | 2只/4；投射1、飞行1 |
| G2 | S03 沉石骑士`ENM-STN-001`；S04 石纹哨像，均未来入口 | G1全灭＋2秒，深入≥40% | 2只/5；冲锋1、投射1 |
| G3 | S05 裂岩守卫`ENM-STN-003`；S06 石纹哨像，均未来入口 | G2全灭＋2秒 | 2只/6；大型1、投射1 |

初始哨像在西北，石蝠在西南真实休眠。蝠保留D-05近触180×85cm/LOS、实伤唤醒、0.80秒苏醒；本组接纳并首次战斗后12秒兜底，或其他已接纳活动敌全灭时唤醒。兜底不提前唤未接纳未来组，不恢复蝠血量/状态，也不取消每轮低空反击窗口。

实例：玩家先杀哨像，蝠仍是本组必需活体，触发“其他活动敌全灭”唤醒；不是房清。玩家先冲过40%线也只锁存G2资格。G1最后一只真死亡记为T，G2最早T+2.00秒接纳、再1.20秒预告后首只显现；若玩家还没到40%，显示“前段已清，继续深入”，等越线才预告。G2全灭后G3同样有2秒喘息、预告和逐只显现。六slot全终态才开主出口。

G2入口优先中北/中南，G3优先东北/东南；不合法则按候选次序重新完整预告。初始蝠的位置固定，不能为了贴近玩家临时换一个“新蝠”。

## 9. 全部模板的异常边界

| 情况 | 必须结果 |
|---|---|
| 深度先到，依赖未清 | 锁存资格，等依赖/喘息/整组预算；不漏事件、不提前隐形出生。 |
| 前组先清，深度未到 | 显示“前段已清，继续深入”，免费通路仍可达；不是roomclear/D-04全安全。 |
| 前组残留休眠、显现中或未出生预留slot | 都未终态；不能按当前正在攻击的数量判整组清。 |
| 快速击杀/跳过敌人的首次攻击 | 真死亡按slot一次结算，无演出复活；未来义务仍存在。 |
| 反复越线、回退、重入 | latch及SpawnID保留，不加波、不回血、不重复奖励。 |
| 出生点复验失败 | 仅未实体slot保留身份重试，重新完整预告；现有实体/血量/掉落不回滚。 |
| 暂停 | 战斗、DoT/CD、喘息、预告、间隔、备用入口计时一起冻结，暂停期间不接纳或出生。 |
| 玩家死亡与组清同点 | 全量伤害/死亡优先，死亡后不新接纳、不实体化、不提交房清成功；未出生slot无死亡奖励。 |
| 前段清而旧弹仍在 | 旧弹/玩家部署/DoT/CD/每房预算继续，不套Boss成功清弹；阶段标签不提供免伤或资源刷新。 |
| 全房清后继续深入 | 终态不可再新增必需怪，主出口按房清接口；后续随机内容必须是预先定义的另一遭遇，不能改写本房清单。 |

同点顺序固定为：**所有到期伤害和死亡 → 连续扫掠/事件锁存 → 存活且预算合法时整组接纳 → 全房manifest清理检查**。房清要求全部必需slot终态，且无存活/休眠/排队/预留/未来必需义务。普通房清不等Boss成功清弹，D-04全安全交互仍需其原有投射物/危险/DoT/待机条件。

每个有限未来slot的真死亡可有一次正常奖励；入口重试、脚本删除、未出生或纯预告没有奖励。价格、数量、掉率、精英品质由D-08另定。本文未生成图像、视频、游戏代码或运行证明。
