# 五区域路线与房间职能设计初稿

日期：2026-10-14；来源：EV-025；模块D-07。区域名称、节点数量、路线和敌池均为助手建议，状态 `design_only` / `assistant_proposed_untested`。尚未建地图、未制作新玩法、未在UE实测寻路；正式命名和故事由D-10定案。数据见[regions-and-routes.json](regions-and-routes.json)，共同规则由本模块根文档另行汇总。

## 事实、推理、风险

事实：用户已确定2.5D横版地牢、九类敌人和局内金币/局外成长方向；现有D-01建议五关，D-06已形成五主线Boss和二可选Boss的设计。本次延续这些建议，不能把“继续”解释为用户亲自指定了50个房间。

推理：采用“预设战斗布局＋路线图随机组装”，使战斗窗口、纵深避让和门可达性能逐个验证。五区主路径均为7节点；额外战斗路线可跳过，商店服务可不购买，不用付费门或跳跃阻断主线。九类敌人按职能跨区混编，区域美术与敌人阵营不一一绑定。

风险：本稿50个候选节点不是50套独立场景美术；同类节点可复用经过验证的布局。每区两战斗分支最多选一个，五条隐藏支路均可跳过，最多访问45个节点；这些数值仍可能因整局节奏调整。单局时长、价格、收益和难度尚未给出可证实的运行依据，交D-08/D-14。拓扑通路存在不能证明身体可通过或Y逃生安全。

## 跨区与返回

R1-N07 → R2-N01 → … → R5-N01，只在各区主线Boss成功后开放对应跨区免费边；JSON的 `destinationref` 记录目标区域/入口，不能把二可选Boss的清理旗标代入。R5-N07到 `RUN-VICTORY` 是D-01/D-06成功事务提交后的自动结算事件边，`ground_route_required:false`，不要求E键或落地待机；它不是步行门。普通导航边均需 `run_active`，最终成功结束本局后不能沿N07回程边继续探索。当前跨区采用单向推进建议，未采用返回上一大关；离开前按D-04展示不可返回、遗留物和持续状态等风险并确认，不悄悄吞掉未选择装备。

区内已清房之间提供显式 `returnable:true` 回程；活动战斗/Boss锁门时不能用此字段逃出尚未清理的遭遇。回访沿用同一RoomInstanceID、manifest、SpawnID和物件记录，不重生敌人、刷掉落、刷新库存或回血；休眠/未触发/未来增援仍计清房，不能将“当前眼前没有怪”误作已清。免费出口能在存在合法旧敌弹或燃烧时离开，但不会净化状态，同点致死伤害先处理；跨房攻击清理与状态保留照D-03/D-04。

## Seed、布局与地面空间接口

新局开始前固定Seed、内容/生成器版本、路图、布局选择和每房有限激活manifest；记录RoomInstanceID、SpawnID、分支选择/发现、清场/奖励与入场资格记录。继续同局不重新生成。D-13尚未完成持久化实现，本稿只定义必存接口。若组装不兼容，在入场前拒绝；只有已验证回退模板才能使用，没有合法回退则让玩家留在局外报告生成失败，不先扣费或发奖励。

主线所有门及路线须地面可达，不依赖跳跃、推拉穿人或收费。深度启动线必须覆盖整个可行Y域，玩家跳过时仍以地面投影记录跨越，但实际过门仍需要D-04落地待机。分段/增援数量由manifest上界确定，禁止实时无穷补怪。

身体与受击体分开：玩家身体半值18×16厘米，当前普通最大参考40×30，Boss最大56×36；门、障碍与走廊要按每个实际身体连续扫掠并加容差。不能只看一张图开口够宽，不能让大体型卡在进场口。Y逃生带还需扣除身体、活动攻击区、墙边和已占位敌人，再检查免费步行路线；Boss用D-06保守129.1875厘米/秒、0.15秒反应压力接口而非只算基础265。石蝠合法低位落点、冲锋截停、实际Z、镜头同时显示来源/区域均需动态验证。

## 本组静态验收与运行边界

本组应静态核：5个区域按既有主线Boss顺序；35主线节点通过仅free边可达；10战斗分支候选各有固定免费回程和汇回；5隐藏候选均有免费回程；门票边全部可跳过；强制完成依赖无环；实际ENM/ELT/BOS引用存在；任意支路不绕Boss跨区。所有已清节点再入不产生新战斗/收益，跨区恢复只按唯一过渡事件一次。

以上只验证规则、引用与图结构，不等于已创建地图、跑通导航、通过墙角反制或完成整局时长平衡。后续D-08定设施/门票/收益，D-10定正式名称剧情，D-11/12定地图UI和场景素材，D-13定存档恢复，D-14以运行游戏验证完整路线。
