# 属性与附魔 v2：共同规则

2026-10-12。状态：原创设计、未接入游戏、未试玩调平衡。用户要求每把武器/每件装备均可有附魔、附魔分几个等级且每级有数值上限、正负词条都存在；**以下五级、词条、数值、概率和费用均为助手本轮方案**，不作为《失落城堡》的准确机制描述。

## 与 v1 的关系

保留 [v1基础装备](../equipment-v1/00-共同规则.md) 和33武器/12防具数值不动；v2以稳定ID引用并扩展，新增基础暴击、附魔、生命上限/治疗效率变化与属性叠加。本文件对这些新增事项优先于v1“无随机暴击/不设随机词条/不变最大生命”的旧范围边界；动作家族、装填/专注、空间判定、切换/换装和无敌等未修改事项继续服从v1。没有新物品或运行代码被制作完成。

## 装备实例和附魔等级

- 全部45个装备定义 `enchantable=true`，等级上限V；未来斧或新装备默认沿用同一接口。本次附魔不改变原始装备ID和固有特色，不把附魔当做武器品质。
- 一件装备只有**一个附魔方案槽**，该方案统一等级I–V，不是五个插槽。三种结果：纯正面 `beneficial`=1正词条；混合 `mixed`=2正+1负；纯负面 `cursed`=1负。无附魔为 `none`，没有等级。高等级增加正/负词条幅度，净收益可能变差；负面不锁装备，不阻止免费丢弃/替换。
- 建议普通投放40%有附魔、60%无附魔；有附魔时60%纯正面/30%混合/10%纯负面，三者总和100%。起步池等级权重I70/II25/III5/IV0/V0，中段I15/II40/III35/IV10/V0，高阶I0/II10/III40/IV35/V15；都是后续来源配置，当前未接掉落。调试柜可直接取任意等级，不受池限制。
- 同方案内词条ID不能重复，同互斥组只能一个；相反词条同组，火/冰/电同属 `elemental`，不能混装。按装备类型过滤：全部武器通用伤害/攻速/削韧/暴击/技冷却/吸血/元素；装填只弩、手枪、霰弹枪、步枪（XBW/PST/SGN/RFL），专注消耗只法杖；延伸距离不用于霰弹。防具保护/生命/专注恢复/治疗效率与武器词条分池；移动词条两者可用。
- 等级只约束幅度；每词条存正整数 `magnitude`，`direction`为±1，实际有符号值=magnitude×direction。`polarity`表好坏，不能用正负数直接推断好坏（降低冷却是好，增加易伤是坏）。所有百分比存“百分数”数值，如12代表12%，计算时除100；护甲/魔抗/韧性为点数。
- 有效数值从该级闭区间等概率取整数，已在全局属性下界无效果、或会让物品自身效果为零的候选不入池。负护甲/魔抗最多扣到0；负防具韧性加成最多扣到0，不能减基础30。先与可用减值求交集，再抽签；该级无合法区间则排除此词条，不能抽到后显示被截断的伪效果。合法组合下全局封顶仍生效，UI同时显示原始词条和实际结果/已封顶原因。

## 属性生效、公式与全局边界

仅**当前手持武器+当前一套身体防具**的附魔生效，第二武器槽休眠。实例存附魔等级、词条ID、幅度、随机种子、算法版本和自身武器技冷却；更换/丢弃不复制、不刷新附魔触发冷却。角色共享状态不能随换装清空。

| 属性键 | 语义和公式 | 边界 |
| --- | --- | --- |
| damage_pct | 所有直接伤害乘 `1+sum/100`，主攻/武器技同用，先修改每段再聚合 | 附魔合计[-30,+50]%；不放大固定元素持续伤害或反复放大第二目标比例 |
| action_speed_pct | 前摇/有效窗/后摇/子窗口时间统一除以 `1+sum/100`；不改变锁定40%比例、输入缓冲或独立技冷却 | [-20,+20]%；动作不低于基础的1/1.2，不低于0.02s的子窗（本轮0.04s窗均满足） |
| stagger_pct | 基础直接削韧乘`1+sum/100`，不放大电震固定附加削韧 | [-25,+25]%，韧性保护照旧 |
| reach_pct | 仅X最大距离乘`1+sum/100`，最小距离/纵深/位移/穿透数不变；火线/霜扇按新的最大X重建形状 | [-15,+15]%；霰弹不入此池，避免悄悄改变散布 |
| crit_chance_pct | 玩家基础5%+当前武器附魔 | [0,20]%；新增v2玩家基础，v1基础伤害表不含期望暴击收益；敌方暴击不在本轮预设 |
| crit_damage_bonus_pct | 暴击倍率`1.5+sum/100`，例如+20为1.7倍 | 最终[1.0,2.0]倍 |
| skill_cooldown_pct | 固有武器技冷却×`1+sum/100` | [-20,+25]%；不改装填/专注延迟或状态内置冷却 |
| reload_speed_pct | 装填时长÷`1+sum/100` | [-25,+25]%；不改拉栓/射击后摇或弹匣容量 |
| focus_cost_pct | 主攻/技能专注成本×`1+sum/100` | [-20,+25]%；浮点成本，按完整一轮预留，不免费降级，基础成本大于0时不能变0 |
| lifesteal_pct | 对真实扣除的直接生命伤害×sum/100回复，不含过量击杀伤害、持续伤害、自伤、无敌拒绝和物件；受治疗者必须存活 | [0,5]%；所有目标/多段每个attack ID最多3HP；角色滚动1s最多6HP（计治疗效率后），不产生新攻击或特效触发 |
| armor_flat | 当前防具基础护甲+附魔点数后代入`min(.6,A/(100+A))` | 护甲[0,150]，减伤≤60%；无甲为0，不把负甲变易伤 |
| ward_flat | 同上但魔抗 | [0,150]，减伤≤60% |
| poise_flat | 基础30+当前防具固有加成+附魔；负词条仅扣固有装备加成 | 总阈值[30,120]；动态替换后当前削韧不变，若已达到新阈值立即破韧一次并遵循保护，不能靠切装清零 |
| max_health_pct | 基础100×`1+sum/100` | [60,150]HP；新上限生效时`CurrentHP=min(oldHP,newMax)`，绝不因穿脱回满/等比例恢复；活着的0<HP<1不抬高（HUD可显示1），死者仍0 |
| move_speed_pct | 防具当前基础/条件倍率×`1+武器与防具sum/100`，再乘265cm/s，再乘出招/装填/受伤限制 | 附魔sum[-25,+25]%，非出招基础倍率最终[.65,1.25]；条件加速仍在出招前结束，不改跳跃高度 |
| focus_regen_pct | 当前防具恢复率（包括静脉站定20/s）×`1+sum/100` | [-25,+25]%；不改变恢复等待或专注上限100 |
| healing_received_pct | 药水/吸血等合法恢复×`1+sum/100`后再做来源与HP上限截断 | [-25,+25]%；不放大附魔换装、不对掉落金币生效 |
| physical_vulnerability_pct | 物理减伤之后收到的伤害×`1+sum/100` | [0,+25]%；只负词条，不另设正面第二层减伤 |
| magic_vulnerability_pct | 同上针对魔法 | [0,+25]%；不会净化或加倍触发状态 |

暴击每次主攻或武器技只抽一次，结果对该次所有子命中/目标共用；霰弹同枪先合计再乘同一倍率，双响同一技能共享暴击结果。直接伤害流程：基础分段→伤害附魔→暴击→目标护甲/魔抗（锥刃局部75%护甲在此步）→目标易伤→扣实际HP→削韧/状态→合法吸血。第二穿透目标仍按基础60%比例一次处理，不能重复乘暴击。DoT不暴击/不吸血/不触发附魔；物理/魔法伤害属性不能让无关加成同时乘两次。

在动作前摇40%锁定点冻结本次攻击者基础值、附魔、资源成本和一次暴击结果，后续子命中/飞行弹沿用该快照；飞行中切换武器、换甲或重洗不追改已经创建的攻击、不重抽暴击。受害者护甲/魔抗/易伤按实际命中时计算。吸血率沿用攻击快照，治疗效率则在实际回复时读取受治疗者当前属性；旧弹不能保留旧甲的治疗加成。主动武器限定新攻击与常驻属性来源，已创建攻击可以正常完成，不能靠切槽把旧弹免费升级。

所有合法治疗（药水、吸血等）先检查受治疗者仍存活；死亡或HP为0时回复0，不消费吸血恢复预算。玩家死亡后旧弹可完成伤害结算，但不能据此复活玩家。本轮没有自动复活词条。

## 元素附魔

元素词条只在**一次攻击中第一个产生正数直接伤害的合法敌人**上触发一次，以实际命中时间、距离、实例ID稳定排序；不能借群攻/多丸挂满屏。各元素触发冷却挂角色：燃烧4s、寒缓3s、电震2s；切武器/换装/重洗不能刷新。电震另服从目标2s、Boss4s内置冷却。技能固有元素仍可按原文打多个目标，但不通过附魔递归扩散。

该敌人是本attack ID唯一的附魔尝试目标。到达该命中时，若角色该元素冷却就绪，先消耗一次角色冷却再尝试施加；即使目标处于韧性保护、目标电震冷却或已有更强状态而拒绝效果，也不退还机会或冷却、不转移到下一个敌人。若当时角色冷却未就绪，本次攻击的后续命中也不再尝试。零直接伤害、无敌拒绝、物件不成为候选且不消耗机会。目标电震冷却仅在额外削韧实际生效时启动，保护/拒绝期间不延长该目标冷却。

首目标被这次直接伤害击杀时，仍按上述规则消费唯一机会和已就绪的角色冷却；尸体不附加燃烧、寒缓或额外削韧，也不改找第二个目标。目标死亡与攻击者死亡是两项独立校验。

- 燃烧幅度是每秒魔法伤害，持续3s，每秒一次；上限6/s（18总额）。已有火线2/s作为同一个目标燃烧槽：强者替换并重置3s，相等刷新，弱者不刷新/不覆盖强者。不削韧、不暴击、不吸血。状态读取施加时幅度，不在切装后追算；施加时的受害者魔抗按每跳当时值结算。
- 寒缓幅度为移动减速%，持续2s，上限25%，Boss减半；与固有20%/Boss10%同槽，取强者/相等刷新/弱者不刷新。不冻结、不减攻击动画速度。
- 电震幅度为额外削韧点，上限10；同次固有8与附魔只取最大值，不相加；保护期间仍受直接伤害但不加削韧、不延后目标冷却。不能强制眩晕。

## 词条目录约定（由专表给具体区间）

共36个建议词条：20正/16负。武器正：锋利damage、轻快action_speed、震击stagger、延伸reach（非SGN）、精确crit_chance、凶猛crit_damage、熟练skill_cooldown（direction=-1）、疾装reload_speed、节能focus_cost（direction=-1，仅STF）、汲血lifesteal、灼热burn、寒意slow、电痕shock。防具正：坚固armor、护纹ward、稳固poise、健壮max_health、凝神focus_regen、复原healing_received。灵动move是武器/防具通用的第20项。

武器负：钝化damage、笨重action_speed、松劲stagger、短锋reach（非SGN）、迟钝skill_cooldown（direction=+1）、卡涩reload_speed、漏魔focus_cost（direction=+1，仅STF）。防具负：破损armor、漏护ward、松散poise、虚弱max_health、散神focus_regen、难愈healing_received、易伤physical_vulnerability（direction=+1）、惧术magic_vulnerability（direction=+1）。拖步move为武器/防具通用第16项。

ID正 `AFF-P-001..020`按上文武器13→防具6→灵动顺序；负 `AFF-N-001..016`按武器7→防具8→拖步顺序。每项JSON字段：`id,name,polarity,group,stat,direction,unit,eligible_kinds,eligible_weapon_families,tiers,rule,exclusions,status`，tiers为5对象`{tier,min,max}`且幅度均正整数。group同stat，三个元素统一elemental。所有status=`design_only`。百分比/点数用整数、所有级区间不交叠（吸血/燃烧/电震等小整数区间可同级唯一值，但下一级不降低）。

机器字段的三个元素stat固定为 `burn_dps`、`slow_pct`、`shock_flat`；它们的group均为`elemental`。unit枚举为`percent`（百分数）、`points`（固定点数）、`damage_per_s`（每秒魔法伤害）。tier存整数1..5，界面显示I..V。

武器数值资格也在抽取前过滤：短锋调整后，主攻与武器技最大X均须仍大于各自不变的最小距离；专注词条调整后，主攻和武器技的完整一轮成本均须在(0,100]（原本0成本保持0）。与该级幅度区间求交集，无合法数值则排除。当前45件均满足；未来新增物品不能只打“可附魔”标记就跳过校验。

五级上限建议：damage正5/10/15/20/25负4/8/12/16/20；action_speed正负4/8/12/16/20；stagger正负5/10/15/20/25；reach正负3/6/9/12/15；crit_chance3/6/9/12/15；crit_damage_bonus10/20/30/40/50；skill_cooldown正4/8/12/16/20负5/10/15/20/25；reload_speed正负5/10/15/20/25；focus_cost正4/8/12/16/20负5/10/15/20/25；lifesteal固定1/2/3/4/5；burn固定2/3/4/5/6每秒；slow固定5/10/15/20/25%；shock固定2/4/6/8/10；armor/ward/poise正5/10/15/20/25负4/8/12/16/20；max_health正5/10/15/20/25负4/8/12/16/20；move正负3/6/9/12/15；focus_regen正负5/10/15/20/25；healing_received正负5/10/15/20/25；两易伤仅负5/10/15/20/25%。非固定整数区间用上一等级上限+1到本等级上限（I从1开始）；所有上限是roll上限不是保证满值。

## 工坊操作与事务

清房后的附魔台操作，不在战斗/攻击/装填/跳跃/换装中执行。觉醒：无附魔变I级，费用20金币；重洗：保等级、整套重抽方案类型与全部词条，费用I15/II30/III55/IV85/V120；升阶：保方案类型、词条ID及其原始抽样百分位q，只映射到下一等级合法区间（整数`min+floor(q*(max-min+1))`，q∈[0,1)，顶端不越max），I→II40/II→III80/III→IV140/IV→V220；洗净：去掉全部附魔，费用I10/II20/III35/IV55/V80。没有合法升级范围则预先拒绝并显示原因，可重洗或洗净，不能悄悄换词条或超上限。负词条升阶也会变重。

先展示固定费用和变更/风险，确认后事务校验金币、实例ID/版本/合法性→扣费一次→使用持久随机流生成并提交一次→重算属性→保存（未来存档接口）。重洗结果立即生效，没有免费预览后取消。失败不扣费、不丢原附魔，不造负金币；反复确认不能重复提交。UI揭示全部词条，正负用文字和符号而非只靠颜色；重洗/升级/洗净均不回复HP、专注、弹药或冷却。提价、碎片、转移、锁词条、保底暂不引入。

随机幅度先用无偏整数抽样，再保存该幅度在本次合法闭区间里的桶中心百分位：`q_num=2*(magnitude-min)+1`，`q_den=2*(max-min+1)`。升阶用 `new_min + (q_num * new_interval_count // q_den)` 精确映射；保留最初q分子/分母，不在每次升阶后重新居中，以免连续升级漂移。固定值区间q为1/2。无合法组合在扣费前拒绝并报告配置错误，不通过改变方案概率或降级凑数掩盖；现有45件×五级须通过全部三种方案资格校验。

本机单人持久随机流只能避免普通读档得到免费新随机，不能宣称防止用户修改本地存档；完整存档尚未实现。经济费用为待实测建议，旧原型每敌5金币不能证明这些价格已经可负担。后续应在完整一局奖励/路线设计后调整，而非擅自承诺刷几分钟能升级。
