# 音频与现有资源核验 v1

2026-10-14，Asia/Shanghai。D-12 / EV-030。助手设计提案，未逐项获用户确认；本轮没有下载、解压写入、转换、生成、播放音频、启动引擎或制作新素材。结构化合同见 [audio-and-assets.json](audio-and-assets.json)。

## 事实、推理与风险

**事实**：本地有8个原始ZIP，实际合计94,920,296字节；归档哈希均与两个旧获取清单一致。8包的1,007个解压文件逐个与ZIP成员字节相符，包内许可文本可读。另有Noto中文字体、64张角色二维帧和5张图标。音频实际为205个OGG，包含23首音乐循环候选、181个独立音效候选和1个RPG整包预览。

**推理**：这些文件足够提供音色试选与二维原型对照，先按“真实事件＋可复用材质”组织，不给每把装备、每个怪或每条事件另开一份素材采购。十一武器家族需要听得出挥动、发射与收势差异，但这些差异仍由原攻击时轴驱动。

**风险**：下载、格式可读、引擎导入、接入代码、试听、混音、循环接缝和发行打包是不同证据。现有3份代表SoundWave不能代表205个文件全部导入，更不能代表完整音效系统已完成。原包PNG可能是纹理或预览，3D动画栈也不能直接计为新的二维动作。音效不能替代可视预告，静音仍须能玩。

## 5. 事件、预警与音乐层

JSON列40个稳定`AUD-*`事件。每条含权威来源、真实触发点、不发声情形、去重键与时钟域；它们是表现订阅，不是伤害、奖励、资源、刷怪或存档提交器。

- 主攻准备/实际挥动/真实发射分开；直接受伤才播唯一接触主声。免疫或落空不能播受伤确认。破韧只在原规则真正接纳破韧状态时发声，不把保护期削韧当成成功打断。
- 同一AcceptedAttackID＋SubHitID＋TargetID只一个接触主声；一个宽扫只一个破风，多目标同材质接触可在建议40ms表现窗内合成、每子段最多2个接触voice。霰弹发射仅一个枪声；连发和双击仍保留真实子段的不同起点。合声不合并伤害收据。
- 死亡声与Boss成功声不同。Boss归零同点玩家死亡只走失败；合法Boss成功才播放一次成功收束。金币/碎片只在实际入账播，地上尚未拾取不先响“获得”。
- 换装、使用物品、购买、强化、附魔、退款等成功声跟真实提交。UI确认是中性按钮声，不代表付款成功；未知提交结果只恢复原记录，不能用“失败声”暗示肯定未扣款。轮盘开奖与托盘领取分别去重，回看不重播完整中奖声。
- 石像、精灵、树人、法袍、骷髅、哥布林、机械、野兽、恶魔采用材质/起音差异；预警开始、原50%锁线与真实恢复开始分别订阅既有事件。恢复点声音只提示已有窗口，不能保证其他敌人和旧弹都停止。
- D07仅已接纳slot真实开始warning时播出生提示，与原1.2s可视预告同步；实体化后仍保留原0.6s显现。未接纳future不提前泄露位置，也不因音乐/提示延后下一波。

## 6. 混音、暂停与跨房

必要预警、终态与玩家受创优先于普通接触，普通接触优先于环境尾音和音乐。建议预警出现时音乐降6dB、非关键战斗声降3dB，20ms入、180ms退；建议24个非关键世界短声、2个UI短声、3个音乐层作为初始混音目标。均未在UE或设备上测量，不是性能保证。必要预警有优先预算，实际密集场景仍需听验；无论声音是否被合成、缺失或静音，可视预告始终保留。

世界声音事件游标跟本局模拟时钟。暂停冻结世界voice游标与游戏音乐进度；可用建议80ms输出淡出避免突兀，这段仅改变音频输出，不推进事件游标。暂停中的UI导航/返回声可独立走UI时钟，不能反向推进DoT、恢复、刷怪、CD或交易。恢复只继续仍有效的声音，不补播已经过去的攻击起点、重复奖励或成功声。

实时比较/购买/出口浮层仍运行，不能因为开音效菜单而获得额外暂停。跳过/即时显示对白只结束文字/非语言语气表现，不快进Boss入场1.5s、阶段提示1.2s、出生1.2s、显现0.6s或真实攻击后摇。本轮不增加游戏快进。

跨波保留仍合法的旧弹、陷阱和状态事件，不能见一波死完就清所有攻击声。普通敌人死亡后已发射弹体的声音跟原弹体继续；Boss只有合法成功清理时才停其自有场上攻击声。离房仅在过门真正提交后清本房声源；角色已附加状态、原next_tick、CD和资源保留，燃烧不因淡出被净化。回到同房可重新起环境底，但不重播清房、首次发现、开奖或奖励成功。

建议音乐转场350ms，仅作输出交叉淡化；不等待音乐播完才开门、结算、进房或推进故事。实际暂停/游标恢复、混音和seek能力留待实现测验，不据设计稿声明引擎已支持。

## 7. 源规格与后续检查

新制作可编辑master建议48kHz/24bit PCM WAV；空间短音用单声道，音乐用立体声，UI居中非空间声。元数据记录来源、许可、原始hash、编辑链、事件ID、loop起止sample和版本。保留原OGG，不为凑规格本轮批量转换；从有损OGG解码WAV不会恢复原本丢失的信息，也不等于原生24bit录音。

需要实际试听和计量后再检查削波、输出峰值、相位、循环接缝、静音替代、扬声器/耳机、暂停/恢复与发行包。建议导出预览true peak不高于−1dBTP是未来目标，不是已测结果。不设未经依据的工期或预算；没有完整配音先保留文本和短非语言语气。

JSON列12项未来检查，覆盖181音效/23音乐选用、十一家族、同事件去重、多目标/霰弹/连发密度、燃烧暂停、旧弹跨波、Boss双死、托盘、免费带DoT出口、字幕关闭与全静音、故事跳过及发行许可。当前只完成本地文件/哈希/清单/头部与设计接口检查，没有听验或游戏运行结论。
