# 永久天赋与属性合并设计初稿

2026-10-14，Asia/Shanghai；来源EV-027用户“ok”；D-09。继续设计是本轮授权，以下9节点、27等级、价格、数值和名称为助手建议，未逐条由用户确认、未实现、未试玩。数据见[talents.json](talents.json)；生命周期/全退/新局快照由`hub-rules.json`定义，总览为根目录《局内成长与局外天赋解锁设计》。原始[D-02角色规则](../player-combat-v1/player-combat-rules.json)、[D-03属性合并](../items-v1/common-rules.json)、[v2属性](../equipment-v2/stat-definitions.json)、[D-08基础强化](../economy-v1/equipment-growth.json)均保留不改。

## 事实、推理、风险

事实：用户已明确收集物用于局外天赋和特殊道具解锁，局内外逐步成长以推进多个大关与Boss。D-08主线重复60碎片、首次主线额外10都是存活完成/普通碎片实际拾取等前提下的设计预算，不是每局保底到账。当前尚未在运行游戏验证零天赋或满天赋通关。

推理：先做三支九节点有限常驻增益，玩家买后都可累计，不设天赋装备槽、互斥职业或无限等级。各支均有低价根节点，后续节点要求少量本支前置，支持先分散尝试再集中投入。完整天赋只用同一stat预算，不在装备、附魔和道具之后再多乘永久倍率。

风险：永久强化可能挤掉局内词条的有效余量；无甲保护会改变旧“无甲0”的派生结果，但不能修改坏词资格。集中刷低章是否比深入有效尚无耗时依据；280是目录总价格，不能换算成固定几局或几分钟。目标仍是操作与局内选择有价值，不能声称已证明不点天赋也必能通关。

## 与装备、附魔、道具合并

每个stat都先合计当前武器、当前甲、遗物/药剂、局内基础强化和本局天赋快照的合法贡献，再使用原cap一次。备用武器附魔/grade不贡献；角色天赋也不因两个武器槽算两份。没有永久伤害第二乘区。

| 属性 | 天赋满额 | 合并后的边界与作用 |
|---|---:|---|
| max_health_pct | +12 | 百分比合计[-40,+50]，基础100生成最终60–150HP。换装仍只向下截当前HP、不治疗；新局合法初始化另按D-01。 |
| armor_flat / ward_flat | 各+6点 | 原防具＋同实例grade增长flat＋合法其他来源＋天赋，再clamp0–150并用A/(100+A)，减伤至多60%。无甲可得各6，但原装备负词资格不变。 |
| healing_received_pct | +6 | 同stat[-25,+25]，仅存活者合法HP恢复；实际恢复时读当前值，再受来源预算与缺血量约束。专注不受药理放大。 |
| damage_pct | +8 | 同stat[-30,+50]；只当前武器主攻/固有技各直接伤害段，不影响道具固定伤害、燃烧、其他DoT或电震点数。 |
| stagger_pct | +6 | 同stat[-25,+25]；只合法武器直接削韧。shock_flat额外点数不放大，保护期/目标ICD不绕过。 |
| crit_chance_pct | +2 | 含基础5%后最终0–20%，一次AttackID一次抽签，全部子段/目标共享；暴击倍率仍按旧规则，天赋不加倍率。 |
| move_speed_pct | +3 | 贡献合计[-25,+25]，再套当前甲基础/条件倍率、待机倍率[.65,1.25]与状态约束；空中XY仍乘.8。闪避185厘米/.4秒及无敌段、跳跃630/g1800/顶点110.25厘米不变。 |
| focus_regen_pct | +9 | 同stat[-25,+25]，乘当前合法恢复基值；不缩消耗等待/站定条件、不改last_spend、不加100上限或瞬间回复。静脉20替换14后才乘。 |
| reload_speed_pct | +9 | 同stat[-25,+25]，时长=基础装填/(1+合计/100)，仅XBW/PST/SGN/RFL。近战/法杖无收益，不缩攻击后摇、不加弹匣或自动填弹。 |

旧D-03“未来天赋合并未完成”由本次新表补充，但原文件保留。未列属性不变：没有动作速度、额外闪避/跳跃/无敌、复活、物品槽、遗物槽、金币/碎片倍率、商店折扣或概率天赋。D-08金额、价格、来源和权重原值保持，不按永久成长实时重刷敌人。

**原始负词资格**：行路短衣原护甲14，grade3增长2.1、满御护6，当前未附魔护甲22.1；破损IV13–16仍只能抽13或14，V17–20仍为空，不能用天赋/强化扩大坏词候选。无甲御护6也不能据此制造“无甲可扣6”的附魔对象。

**治疗边界**：药理满级+6时赤莓小药基准30成为31.8候选，但实际不超过缺血。吸血若扣敌真实100HP、率5%，乘效率1.06得到5.3候选，随后仍受每AttackID3HP、滚动1秒6HP约束；当前缺10时实际3。死者回复0且不消耗治疗预算，不借旧弹复活。

**时间与快照**：D-03接受攻击起点固定整套动作时间轴，前摇40%锁定伤害、成本、暴击及其他预算；一次AttackID共享暴击结果。天赋不改变此规则，也不追改已发射攻击。目标护甲/魔抗/易伤、实际治疗效率仍按命中/恢复时当前值。专注恢复增加率，不缩等待；枪弩增加装填率，不把它换成攻速。
